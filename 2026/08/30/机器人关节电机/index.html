机器人关节电机

关节电机 无刷电机 FOC 谐波减速器 行星减速器 电机控制
机器人理论与技术 机器人零部件
发布日期:   2026-08-30

关节电机是机器人的”肌肉”：人形全身几十个、机械臂六七个、灵巧手每个手指两三个。一个现代关节模组 = 电机（产生扭矩）× 减速器（放大扭矩）× 编码器（知道转到哪）× 驱动器（决定怎么动） 的四合一集成件。本文按这条链逐层拆开：电机原理（有刷/无刷/空心杯/步进）、控制原理（六步换相 → FOC 矢量控制 → 级联环 → MIT 力控模式）、减速器原理（行星/谐波/RV 摆线）、架构选型（直驱 vs 准直驱 vs 高减速比），并给出两个实测通过的 Python demo（FOC 的 Clarke/Park 变换、电机-减速器选型计算）。与传感器篇（编码器）、动力学基础（惯量与扭矩）衔接。

1. 关节电机模组：四件套集成

集成化的原因：分立件之间的线缆（三相线 + 编码器线 + 通信线）是机器人本体最脆弱的环节；一体化后模组对外只留一根电源 + 一根总线（CAN/CAN-FD/EtherCAT，见通讯篇）。

2. 电机原理详解：逐类拆解

一切电机共同的物理起点是洛伦兹力：载流导体在磁场中受力 \(\boldsymbol{F} = I\boldsymbol{L} \times \boldsymbol{B}\)；旋转视角下这就是电磁转矩，\(\tau = k_t i\)。各类电机的差异，全在于”怎么让导体里的电流方向与磁场方向始终垂直”——有刷用机械换向，无刷用电子换相，步进用磁阻最小原理，音圈用直线路程。逐类展开。

2.1 有刷直流：机械换向与机械特性推导

结构：定子永磁体（磁钢提供 \(\mathbf{B}\)），转子（电枢）绕组由换向器 + 电刷供电。转子转到任何角度，电刷通过换向片把电流切入”此刻正好在 N/S 极下、导体运动方向与磁场垂直”的那组绕组——电流方向随位置机械切换，转矩方向恒定。

转矩与反电动势的一体性：同一绕组既是电动机（通电受力 \(\tau = k_t i\)）又是发电机（切割磁链感生 \(e = k_e\omega\)），\(k_t = k_e\)（国际单位制下数值相等）。电枢回路电压平衡：

\[ U = R i + e = R i + k_e \omega \quad\Longrightarrow\quad i = \frac{U - k_e\omega}{R} \]

代回转矩公式得到机械特性（T-n 直线）：

\[ \tau = k_t\,\frac{U - k_e\omega}{R} \]

两个端点就是数据手册的关键值：堵转扭矩 \(\tau_{stall} = k_t U/R\)（\(\omega=0\)，电流最大、发热最狠）与空载转速 \(\omega_0 = U/k_e\)（\(\tau=0\)）。加电压就转、降电压就慢，控制被这根直线完全描述——这是它”两根线”之简单的原因。

淘汰它的原因也来自换向器：电刷与换向片滑动接触，磨损（千小时级寿命）、换向瞬间电感断流产生火花（EMC 污染 + 电蚀）、摩擦转矩占比随小型化升高。机器人关节已淘汰，仅存于微型泵、廉价夹爪。

2.2 永磁同步电机（BLDC/PMSM）：旋转磁场的合成

结构反转：把绕组放定子（静止、好散热）、永磁体放转子（无滑环、无磨损）——这就是”无刷”。剩下的唯一问题：定子磁场必须自己转起来。

旋转磁场怎么来：空间上相差 120° 的三相绕组，通时间上相差 120° 的正弦电流，三相磁动势合成一个幅值恒定、匀速旋转的合成磁动势（幅值为单相的 3/2 倍），转速 = 电流角频率（电角速度）。合成磁场拖着转子永磁体同步旋转——两块磁铁式的转矩。反电动势由转子磁链扫描定子绕组产生，绕组匝链的磁通波形决定了反电动势波形。

绕组形式决定”BLDC 还是 PMSM”：

  • 集中绕组（每齿绕一相、节距 1 槽）：磁链波形接近梯形 → 反电动势梯形波 → 配方波六步驱动 = 传统意义的 BLDC（绕组短、铜耗低、工艺便宜，但有转矩纹波）
  • 分布绕组（跨槽分布、短距）：磁链正弦化 → 反电动势正弦波 → 配正弦电流 FOC = PMSM（平滑、低噪声、低纹波）

硬件连续谱、按驱动方式命名，现代关节电机全部按 PMSM + FOC 使用（第3节）。

转子磁路两种：SPM 与 IPM：

  • 表贴式（SPM）：磁钢贴在转子表面，交直轴电感相等 \(L_d = L_q\)，转矩只来自永磁体：
\[ \tau = \tfrac{3}{2} p\, \psi_f\, i_q = k_t i_q \qquad (\text{纯 } i_q \text{ 控制}) \]
  • 内嵌式（IPM）：磁钢埋入转子铁芯，气隙不均匀 → \(L_d < L_q\)，凸极效应贡献磁阻转矩：
\[ \tau = \tfrac{3}{2} p\,\big[\psi_f i_q + (L_d - L_q)\, i_d i_q\big] \]

第二项与 \(i_d\) 相关——负 \(i_d\) 也能出转矩（磁阻转矩），IPM 可用 MTPA（最大转矩电流比）策略弱磁高速。关节电机以 SPM 为主（控制简单、\(k_t\) 线性），IPM 常见于需要高速弱磁的场景（无人机动力）。

内转子 vs 外转子：内转子惯量低（伺服友好）；外转子（定子在里、磁钢杯在外）同样的绕组能挂更多磁极、气隙半径大 → \(k_t\) 大、转速低——云台/无人机/部分关节电机的选择，代价是转子惯量大。

齿槽转矩的物理：转子旋转时磁路磁阻随定子齿槽位置周期变化，磁共能对角度的导数不为零 → 不通电也有脉动转矩。每转波动次数 = 槽数与极数的最小公倍数（12 槽 14 极 → 84 次/转）。抑制三招：斜极/斜槽（把周期性错开平均掉）、分数槽绕组（12N14P 本身就是分数槽）、驱动端谐波前馈补偿。

极对数 \(p\)：电角度 = 机械角度 × \(p\)。多极 → 同样电频率下机械转速更低、转矩密度更高，但铁损随极数上升、高速时电频率高对电流环带宽压力大。关节电机典型 5~14 极。

2.3 空心杯电机：去掉铁芯的得与失

结构：定子永磁体 + 杯状自支撑绕组转子（无铁芯，铜线绕成杯 + 树脂定型，通过换向器或无刷形式供电——机器人用的是无刷空心杯）。

得（全部来自”没有铁芯”）：

  • 无铁损：铁芯的涡流损耗与磁滞损耗消失，效率可达 90%+
  • 零齿槽：没有齿槽结构就没有磁阻脉动
  • 电气时间常数极小：\(\tau_e = L/R\)，无铁芯电感 L 小一个数量级 → 电流上升 µs 级 → 电流环带宽极高
  • 转子惯量低一个数量级：只剩铜杯，加速度可达 10⁵ rad/s² 量级——指尖关节毫秒级响应的物理基础

失（也来自”没有铁芯”）：

  • 气隙大（绕组杯占掉磁路空间）→ 有效磁密低 → 同体积扭矩密度不如有铁芯电机
  • 热瓶颈：绕组是发热体，又没有铁芯做导热路径，热量只能靠空气与轴传出——过载能力秒级，堵转几秒就可能烧
  • 工艺贵（杯型绕组制造）

定位：灵巧手指尖、光学调焦、高速扫描等”要响应不要持续扭矩”的场合（Maxon、Faulhaber），与灵巧手综述的腱绳方案配套——电机放前臂，低惯量让腱绳往返的动态跟得上控制带宽。

2.4 步进电机：三种原理与微步

磁阻式（VR）：转子是凸极软铁（无磁钢），通电相绕组磁化磁路，转子被拉向磁阻最小（磁路最对齐）的位置。结构简单、步距大，转矩小。

永磁式（PM）：转子永磁体，定子通电极对转子磁极吸引/排斥定位。步距粗（7.5°~15°），便宜（打印机/云台）。

混合式（HB = VR + PM）：转子 = 永磁体 + 两端带齿的软铁段（齿错开半个齿距），兼具 VR 的细步距与 PM 的大转矩——两相 HB 典型 50 齿 → 每转 200 步、1.8°/步，是”步进电机”的默认含义。

微步原理：不按通断驱动，而是给两相绕组通幅值按 sin/cos 变化的细分电流（\(\sin\theta, \cos\theta\)），合成磁场连续旋转，转子停在两步之间的任意插值角——16/32/256 细分让 1.8° 变成 0.1° 级。注意微步提高的是分辨率不是精度（负载下仍会偏），且低速细分会暴露转矩波动。

失步与共振：开环是本性——负载超过保持转矩或加速度超过牵入能力就丢步且无从得知（位置谎言）；绕组-转子构成弹簧质量系统，低频（1~2 kHz 驱动脉冲附近）有共振区。这是关节不用它、夹爪滑台敢用它的分界线。

2.5 音圈电机（VCM）：洛伦兹力的直线形态

原理最纯粹的电机：导体放在恒定磁场里，\(F = B L i\) 直线力，无换向、无齿槽、无滞后——电流到力的传递带宽只受电感限制。行程 mm~cm 级（硬盘磁头臂、摄像头对焦、光学快门都是它），响应可达 kHz。机器人用途：高速夹爪（毫秒级开合）、主动隔振平台、触觉激励器。与力位混合控制的”零刚度直驱”天然匹配（力位混合控制直驱讨论）。

2.6 直线电机与力矩电机：直驱的两种形态

  • 直线电机：把旋转电机”展开铺平”——永磁轨道（定子）+ 线圈滑块（动子），无丝杠等中间传动 → 无背隙、无限行程、带宽高。有铁芯（推力大、有齿槽）与无铁芯 U 型（无齿槽、轻）两支。用于高端 XY 平台、直驱滑台；成本与防磁污染是门槛
  • 力矩电机（torque motor）：大直径、多极、扁平的 PMSM——牺牲转速换力矩：气隙半径大 + 极对数多 → \(k_t\) 巨大。配直接输出（无减速器）用于机床转台、雷达、机器人肩髋等需要大扭矩高透明性的直驱轴（第5节直驱架构的硬件基础）

2.7 读懂电机的参数语言

参数 含义 选型含义
\(k_t\)（N·m/A） 转矩常数 相同电流出多少力矩；FOC 下 \(\tau = k_t i_q\)
\(k_e\)（V·s/rad） 反电动势常数 决定最高转速（\(k_e = k_t\)，单位制一致的同一物理量）
额定 vs 峰值扭矩 连续散热允许 / 短时（秒级）允许 峰值看加速与冲击，额定看稳态热
机械特性 / 矩速曲线 \(\tau = k_t(U - k_e\omega)/R\) 及其 FOC 等效 工作点必须落在曲线内
转子惯量 \(J_m\) 电机侧惯量 决定力控透明性（第5节）
电气时间常数 \(L/R\) 电流响应速度 空心杯 µs 级，有铁芯 ms 级
槽极配合（如 12N14P） 定子槽数:转子极数 分数槽 → 低齿槽；lcm(槽,极) = 齿槽波动次数

3. 控制原理：从六步换相到 FOC

3.1 六步换相（梯形波控制）

用三个霍尔传感器知道转子位置（六个扇区），每个扇区导通固定的两相绕组——三相电流是方波，合成磁场是步进的六边形。简单廉价，但每换相一次转矩波动一次（纹波大）、电流环无法连续调节——用于风扇、无人机，不适合关节。

3.2 FOC 矢量控制：把交流电机当直流电机控

FOC（Field Oriented Control，磁场定向控制）的核心思想：通过坐标变换，让旋转的三相系统在”转子坐标系”里变成两个恒定的直流量——\(i_d\)（励磁分量，与磁链平行，不产转矩）和 \(i_q\)（转矩分量，与磁链正交）。于是转矩控制退化为 \(\tau = k_t i_q\) 的”直流电机”问题。

全链路（每 1050 µs 执行一次，电流环 20100 kHz PWM）：

Clarke 变换（abc → αβ，等幅值形式，把三相化为两相正交）：

\[ i_\alpha = i_a, \qquad i_\beta = \frac{i_b - i_c}{\sqrt{3}} \]

Park 变换（αβ → dq，旋转到转子坐标系，\(\theta_e\) 为电角度）：

\[ i_d = i_\alpha \cos\theta_e + i_\beta \sin\theta_e, \qquad i_q = -i_\alpha \sin\theta_e + i_\beta \cos\theta_e \]

控制策略（表贴式永磁）：\(i_d^* = 0\)（不励磁，纯转矩），\(i_q^* = \tau^*/k_t\)。两个 PI 电流环把 \(i_d, i_q\) 钉在给定值上，再反变换回三相电压经 SVPWM 输出。（内嵌式永磁 IPM 还可用 MTPA 利用磁阻转矩，关节电机少用。）

3.4 无感控制

不装编码器/霍尔，用观测器（滑模 SMO、磁链观测、HFI 高频注入）从电压电流反推转子位置。机器人关节必须要编码器做输出端位置反馈（无感精度不够），但无感用于启动（从静止把 PMSM 拉起来）与冗余。

3.5 级联控制环与 MIT 力控模式

驱动器内部的三环级联（外环给内环设定值）：

关节力控的流行变体是 MIT Cheetah 模式（一条报文全给定，CAN-FD 的标准指令帧，见通讯篇CAN-FD 节）：

\[ \tau_{cmd} = k_p (q_d - q) + k_d (\dot{q}_d - \dot{q}) + \tau_{ff} \]

位置刚度 \(k_p\)、阻尼 \(k_d\)、前馈力矩 \(\tau_{ff}\) 三个量在线可调——同一关节在”位置伺机/阻抗回零/纯力矩”之间无缝切换，是腿式/人形全身控制的标准接口。

3.6 驱动器的控制模式全景：底层接口怎么选

驱动器对上层暴露的”控制模式”就是接口层级——上层控制器越强，底层接口越该”原始”（带宽与灵活性最高）；层级越高越省心，但带宽越低、越不透明：

模式 驱动器内部闭环 上层下发 典型用途
电压/占空比 无 duty 航模电调、玩具（机器人不用）
电流（力矩）模式 电流环 \(i_q\) / \(\tau\) 机器人外层控制器的首选——动力学、力控、全身控制在主控侧自己跑
速度模式 电流 + 速度环 \(\dot{q}\) AGV 轮、泵、回零阶段
位置模式 三环全用 \(q\) 传统机械手、PLC 点位控制
MIT/阻抗模式 电流环 + 关节级 PD \(k_p, k_d, q_d, \tau_{ff}\) 关节模组标配（DM/AK/宇树）

经验：跑 ROS/全身控制器的主控选力矩模式（模型在外层，见ROS 规范分层）；无主控模型的独立轴（升降、夹爪本体）选位置/速度模式省事；腿式与灵巧手关节选 MIT 模式做两者之间的折中。

3.7 参数整定：三环的带宽金字塔

电流环（解析整定）：电机相绕组是一阶 RL 负载，PI 参数用零极点对消法直接算出来，不用试凑：

\[ K_p = \omega_c L, \qquad K_i = \omega_c R \]

\(\omega_c\) 是目标电流环带宽，取 PWM 频率的 1/101/20（20 kHz PWM → 12 kHz）。验证标准：阶跃响应无超调、无振荡（电流环超调会在力矩上打齿）。

速度环与位置环（逐层 ×1/5 降带宽）：

\[ K_{p,v} = \omega_v \hat{J},\quad \omega_v \approx \tfrac{\omega_c}{5}; \qquad K_{p,p} = \omega_p^2 \hat{J},\quad K_{d,p} = 2\zeta\omega_p \hat{J},\quad \omega_p \approx \tfrac{\omega_v}{5} \]

\(\hat{J}\) 是折算到该轴的总惯量（动力学基础）——惯量不准，外环增益全错，驱动器的”惯量辨识”功能就是在线激振估计 \(\hat{J}\)。

环 典型带宽 关键参数 整定方法
电流环 0.5~2 kHz \(K_p{=}\omega_cL,\ K_i{=}\omega_cR\) 解析计算 + 阶跃验证
速度环 100~400 Hz \(K_p{=}\omega_v\hat J\) + 积分 惯量辨识后计算，阶跃微调
位置环 20~80 Hz PD（+积分慎用） \(\omega_p\)、\(\zeta{=}0.9{\sim}1\)，五倍分离

带宽金字塔的意义：外环必须比内环慢约 5 倍，否则外环”追不上”内环的动态，互相激励振荡。

3.8 前馈、滤波与补偿：误差的下半场

反馈（PD）管”出了错拉回来”，前馈管”提前抵消已知的扰动”——跟踪精度的大头在前馈：

  • 惯量前馈：\(\tau_{ff} \mathrel{+}= \hat{J}\ddot{q}_d\)（轨迹规划器给出期望加速度）
  • 重力前馈：\(\tau_{ff} \mathrel{+}= \hat{g}(q_d)\)（动力学基础的 \(\boldsymbol{g}(\boldsymbol{q})\)，参数来自参数辨识）
  • 摩擦前馈：\(\tau_{ff} \mathrel{+}= \hat{F}_v \dot{q}_d + \hat{F}_c\,\mathrm{sign}(\dot{q}_d)\)（黏性 + 库仑，辨识可得）

滤波与补偿技巧（每条对应一类真实问题）：

  • 电流采样低通：截止 ≈ PWM 频率/5，滤开关纹波；采样点选 PWM 周期中点（低边开关噪声窗口外）
  • 速度滤波：编码器差分的速度噪声大（M/T 法 + 低通，或 Luenberger 观测器——速度环增益被噪声卡住时先查这里）
  • 力矩/指令斜坡（slew limit）：目标突变限幅，保护减速器冲击
  • 积分抗饱和：接触/限位时误差长期同号，积分必须钳位或反算，否则松开瞬间”报复性”超调
  • 逆变器死区补偿：功率管防直通插入的死区时间在低速造成电压畸变与 5/7 次谐波力矩纹波——低速轻载抖动的隐形元凶，驱动器里叫”死区补偿”
  • \(k_t\) 温漂：钕铁硼剩磁温度系数约 −0.12%/K，长时间大电流后”同样的电流出的力变小”不是错觉——力矩估计要乘温度补偿

3.9 PID 家族：变体原理与使用场景

PID 的三项各有物理身份：P 是刚度（误差越大拉得越狠，”现在”）、I 是记忆（消除稳态误差，”过去”）、D 是阻尼（抑制超调，”未来”）。关节控制的各环从不裸用完整 PID，而是按对象特性裁剪：

结构 用在哪 为什么
PI（无 D） 电流环、速度环 一阶对象无需 D；电流采样噪声大，D 会把噪声放大成力矩毛刺
PD（无 I） 位置环、MIT 模式 二阶对象 D 给阻尼；有重力/摩擦前馈时稳态误差已消，I 反而添乱（力位混合控制 Lyapunov 全局稳定的正是 PD+重力补偿）
PD + 小 I 精密位置伺服 消除剩余稳态差（齿槽、装配偏心），但 I 必须配抗饱和
级联 PI-PD 三环结构 3.7 节带宽金字塔

在此之上是一族工程变体（每个变体解决一类真实病症）：

① 积分抗饱和（Anti-windup）。误差长期同号（顶死限位、堵转）时积分器”充爆”，退出饱和后释放出巨大反向超调。两种修法：

② 积分分离。大误差时干脆切除积分、只用 PD 接近；误差进入小带（如 ±2% 量程）再投入积分清尾差——大阶跃启动不过冲的标准做法，回零/换向频繁的关节必开。

③ 微分先行（D on measurement）。D 项作用在测量值而非误差上：\(\tau = K_p(q_d - q) - K_d\dot{q}\)。设定值突变的瞬间，误差微分是 \(\Delta q_d/\Delta t\) ——一个巨大的假信号（微分踢）：

两条物理直觉：设定值自己不会动，它的微分只该反映测量量的变化；期望速度可由 \(\dot{q}_d\) 单独前馈，不劳 D 项。

④ 增益调度（Gain Scheduling）。机械臂关节的等效惯量随构型变化（\(\mathbf{M}(\boldsymbol{q})\)，肩关节远近构型可差 3~10 倍，见动力学基础）——固定增益在轻载构型过刚（振荡）、重载构型过软（跟踪差）。修法：按 \(\hat{J}(q)\) 在线更新增益 \(K_p = \omega_p^2 \hat{J}(q)\)（调度源：模型计算或在线惯量辨识），增益随构型”呼吸”。

⑤ 前馈复合控制（3.8 节）：PD 管未知扰动、前馈管已知动力学——实测把跟踪误差压到 2.7%。

⑥ 自抗扰 ADRC（一页纸版）：不区分摩擦/重力/负载变化，统一当”总扰动”用扩张状态观测器（ESO）实时估计并补偿——不需要精确模型，对减速器摩擦变化鲁棒；国产高性能驱动器已开始内置。调参量少（带宽化），但观测器带宽与噪声的折中要试。适合”模型懒得辨识又要性能”的量产关节。

选型速查：

场景 推荐 一句话理由
电流/速度环 PI 一阶对象 + 噪声
关节位置（有前馈） PD Lyapunov 可证全局稳定
精密点位（换向少） PD + 抗饱和 I 清尾差
频繁阶跃/轨迹拐点 微分先行 杀微分踢
大阶跃回零 积分分离 + 斜坡 防过冲
变构型机械臂 增益调度（按 J(q)） 增益随惯量呼吸

4. 减速器原理

4.1 为什么必须减速

电机的高效区在”高速低扭矩”，关节需要”低速大扭矩”——减速器完成这个变换：\(T_{out} = N\,\eta\, T_{in}\)，\(\omega_{out} = \omega_{in}/N\)。代价：背隙（空程）、弹性（刚度）、摩擦、寿命。关节设计的一半艺术在选减速器。

4.2 行星轮系：一级行星

太阳轮（输入）驱动 2~4 个行星轮，行星轮在外圈齿圈内滚动，行星架（输出）：

\[ i = 1 + \frac{z_{ring}}{z_{sun}} \qquad \text{（齿圈固定）} \]

单级 3~10（如 \(z_{sun}{=}12,\ z_{ring}{=}84\) 时 \(i{=}8\)），多级串联到 100。特点：同轴输出、功率密度高、便宜；缺点：背隙（arcmin 级，精密级预紧后可到 <1 arcmin）、多级后效率下降。准直驱关节的标准选择。

4.3 谐波减速器：柔性变形的艺术

三个零件：波发生器（椭圆凸轮 + 薄壁柔性轴承，输入）+ 柔轮（薄壁杯状弹性件，外齿，输出）+ 刚轮（内齿圈，固定）。波发生器把柔轮撑成椭圆，椭圆长轴处柔轮外齿与刚轮内齿啮合：

  • 传动原理：柔轮齿数比刚轮少（通常差 2 齿）。波发生器转一圈，啮合位置转过柔轮全部齿，而柔轮相对刚轮”退”了 2 齿——减速比：
\[ i = \frac{z_{flex}}{z_{rigid} - z_{flex}} \qquad \text{（如 } z_f{=}200, z_r{=}202 \Rightarrow i=100\text{）} \]
  • 特点：多齿同时啮合 → 零背隙、高精度（arcsec 级）、单级 50160、同轴、体积小；柔轮周期性变形 → 疲劳寿命有限（数千数万小时，随负载折减）、刚度低且有”软”区、高速发热
  • 柔轮的形变测量还顺便提供了关节力矩传感的机会（在柔轮或输出端贴应变片——传感器篇4.6 节）

4.4 RV 减速器（摆线针轮）：大扭矩的抗冲击王者

两级结构：第一级渐开线行星（粗减速）+ 第二级摆线针轮（偏心轮带动摆线轮，摆线轮的摆线齿廓沿针齿滚动啮合，输出经曲柄轴）。特点：扭矩密度最高、抗冲击过载能力极强、刚度大、寿命长；但笨重、贵。用途：大负载工业臂的底座三轴（腰、肩、肘），与谐波（腕部三轴）分工。

行星 谐波 RV/摆线

5. 关节架构：直驱、准直驱与高减速比

折算惯量与透明性是架构选择的核心物理量。从负载侧看，电机转子惯量被放大 \(N^2\) 倍：

\[ J_{\text{eq,load}} = N^2 J_m + J_L \]
  • 直驱（N=1）：无背隙无谐振、力矩最透明（碰撞安全）；但电机要直接输出全部扭矩——体积重量大。只有力矩密度极高的电机（如 T-Motor 级外转子）+ 特定场景（小负载）
  • 准直驱（N=6~10，行星）：MIT Cheetah/宇树路线。\(N^2=36\sim100\)，转子折算惯量仍可控，背隙小、带宽高，配合 MIT 模式做高透明力控——腿式/人形主流
  • 高减速比（N=50~160，谐波）：协作臂路线。位置精度与功率密度最优；\(N^2 \sim 10^4\) 的折算惯量让碰撞力巨大——只能靠力矩传感器（而非电机电流）实现安全力控（Franka 方案）

一条经验：减速比越高，越需要”外置力感”；减速比越低，电流环就是力传感器。

7. 选型计算（可运行，实测）

给定负载需求，扫描减速比找可行域——三条约束：电机转速 ≤ 额定、电机侧扭矩 ≤ 峰值、折算惯量比（负载折算到电机侧与转子惯量之比，伺服推荐 1~10）：

读表：N=1 需要电机直接出 29.4 N·m（不可能），惯量比 4545（完全失控）；N=25 起进入可行域。力控关节选最小可行 N=25（透明性最好，惯量比 7.3 仍在推荐域）；纯位置关节可选 N=50~80（惯量比更接近 1，动态更”紧”）。选型三步：负载折算 → 约束扫描 → 按架构理念（透明 vs 精度）定 N，最后核对连续扭矩需求 ≤ 额定值（热设计，见 \(I^2R\) 与绕组温升）。

8. 总结

层 关键词 一句话
电机 BLDC/PMSM、空心杯、\(k_t\) 关节全是 FOC 驱动的正弦永磁同步；空心杯 = 灵巧手
控制 Clarke/Park、\(i_d^*=0\)、三环级联、MIT 模式 坐标变换把交流变直流：\(\tau = k_t i_q\)
减速 行星 310 / 谐波 50160（零背隙）/ RV（抗冲击） 减速比 = 扭矩 × N，惯量 × N²
架构 直驱 / 准直驱 / 高减速比 N² 折算惯量定透明性；减速比越高越需要外置力感
选型 转速、峰值扭矩、惯量比三约束扫描 力控选最小可行 N，位置选惯量比≈1

一句话：关节 = 把”高速小扭矩的电”变换成”低速大扭矩的力”的机器——FOC 管前半段（电→电磁转矩），减速器管后半段（转矩放大），编码器与动力学模型（动力学基础）把两端联系起来。选型时记住 \(N^2\)：它同时决定了你的力控透明性和碰撞安全性。
