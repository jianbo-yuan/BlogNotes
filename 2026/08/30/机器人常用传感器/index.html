机器人常用传感器

传感器 编码器 IMU 力传感器 视觉传感器 激光雷达
机器人理论与技术 机器人零部件
发布日期:   2026-08-30

机器人 = 感知 + 决策 + 执行，传感器是三者的起点。本文按本体感知（proprioceptive，感知自身状态）与外部感知（exteroceptive，感知环境）两大类，覆盖机器人最常用的传感器：编码器、IMU、力/触觉、视觉、激光雷达、短程距离、定位辅助与杂项——每种讲原理、使用要点、代表性厂家，并给两个实测通过的 Python demo（正交编码器解码、IMU 互补滤波）。硬件接口部分与串口协议篇衔接。

2. 编码器（位置传感器）：关节的眼睛

2.1 增量式：正交信号与插值细分

光电增量式的物理链路：LED → 码盘（玻璃上镀铬刻线）→ 指示狭缝 → 光电管。刻线扫过时输出近似正弦的模拟信号，A、B 两路相位差 90°（正交），Z 为每转一过的索引脉冲。

两个精度层次：

  • 数字四倍频：把正弦整形成方波，对 AB 边沿计数（2.6 节 demo 的状态机就是它）——这是精度的下限，1000 线 → 4000 计数/转
  • 模拟插值细分：直接对 \(\sin/\cos\) 原始信号做 \(\arctan(\cos/\sin)\)，一个信号周期内再切 \(2^{16}\) 份——2048 线 + 16 位插值 = 2²⁵ ≈ 3300 万计数/转（约 0.04 角秒）。高分辨率编码器的秘密全在模拟前端的信号质量（幅值对称、谐波小、正交误差小）

测速三法：M 法（固定时间数脉冲，高速准）、T 法（测脉冲间隔，低速准）、M/T 混合（全程可用，伺服驱动器标配）。

2.2 绝对式：格雷码、多圈与磁/感应家族

为什么是格雷码：相邻两个码字只变 1 位。二进制码在 0111→1000 跳变时四位同时翻转，读数瞬间可能读到过渡态的任意组合（毛刺）；格雷码逐位过渡，读数永远落在相邻两个合法码字之一。单圈绝对 = 码盘上 N 条同心格雷码轨道；工艺上限后，”粗码道 + 精细增量轨”组合可到 20+ 位单圈。

多圈绝对的真伪：机械齿轮组（真多圈，断电后圈数仍在齿轮位置里）；电池/Wiegand 磁记忆（伪多圈，断电靠低功耗计数器或维甘德传感器记录圈数——多摩川方案就是电池绝对）。

磁编码物理：径向充磁磁钢 + 磁场方向传感器。三代敏感元件：霍尔（测磁通垂直分量，便宜，精度一般）→ AMR 各向异性磁阻（惠斯通电桥结构，对磁场方向敏感，精度高一档）→ TMR 隧道磁阻（灵敏度更高）。磁编码的坑：外部磁场干扰（电机绕组漏磁！）与温度漂移——所以驱动板上磁编码器通常加磁屏蔽罩。

电容/感应式：线圈极板间电磁耦合/电容变化测角，不怕油污粉尘与强振（机床与重载伺服的选择）。

2.3 精度分解：分辨率 ≠ 精度

概念 含义 典型量级
分辨率 能分辨的最小角度 磁编码 1218 bit；光电绝对 1723 bit
精度（指示误差） 指示角 − 真实角 磁编码 ±0.1°0.5°；光电绝对 ±1060 角秒
重复性 回到同一点的散布 通常优于精度的 1/3

误差来源分解：刻线误差（码盘制造）、偏心误差（码盘中心与转轴不重合，误差呈一次谐波——安装同心度是用户能控制的最大项）、插值误差（sin/cos 幅值不对称与谐波）、安装倾斜与轴系窜动。高端编码器出厂自带误差表电子补偿；整机厂做的则是联机标定（对比高精度基准，把残差写进驱动器查表补偿）。

3. IMU：姿态与平衡的根基

3.1 原理

MEMS 加速度计：检测质量块被加速度”压”在弹性梁上，电容极板间距变化 → 电容差 → 加速度。静止时测的是重力分量（所以它能给绝对姿态），运动时是重力+运动加速度的混合（所以它动态不可信）。

MEMS 陀螺仪：驱动质量块高频振动，输入角速度在正交方向产生科氏力，引起检测电容变化 → 角速度。测的是角速度，姿态要积分——积分就有零偏（bias）漂移，分钟级能漂出几度。

两者的缺陷恰好互补：加速度计低频准（重力基准）、陀螺高频准（不受运动加速度干扰）——于是有了融合滤波器（互补滤波/Madgwick/EKF，状态估计课程的主角）。

等级划分（选型先对号入座）：

等级 陀螺零偏不稳定性 代表 机器人用途
消费级 10~100 °/h BMI088、ICM-42688、LSM6DS 系列 平衡控制、姿态监测
工业级 1~10 °/h Xsens MTi、Lord Microstrain 3DM 系列 腿式/无人机导航、动捕
战术级 0.1~1 °/h Honeywell HG 系列、Epson 高精陀螺 组合导航（+RTK）
导航级 <0.01 °/h 光纤/激光陀螺 惯性导航，机器人极少用

3.2 使用要点

  • 安装：轴向与机体坐标严格对齐（装歪 1°，重力补偿全错）；机身减振垫隔离电机高频振动，否则陀螺饱和
  • 采样与同步：加速度计和陀螺必须同一时刻采样（片内 FIFO 或硬件同步），融合器对时间戳错位极其敏感
  • 动态场景（腿式机器人）：加速度计被运动加速度污染，融合权重往陀螺倾（或直接 EKF+运动学先验）
  • 室外组合导航：IMU + GNSS/RTK 互补（IMU 高频短时准，RTK 低频绝对准）

4. 力与触觉：接触的感知

4.1 应变片物理：从形变到电压

金属应变效应：导体被拉伸时电阻 \(R = \rho L/A\) 的几何项变化，相对变化率与应变 \(\varepsilon\)（无量纲，µm/m 记 µε）成正比：

\[ \frac{\Delta R}{R} = K \cdot \varepsilon, \qquad K \approx 2\ (\text{金属}),\quad 100\text{~}200\ (\text{半导体压阻}) \]

半导体压阻片灵敏度高两个数量级（能带结构受应力调制），但温度系数大、量程小——高精度 F/T 仍以箔式金属应变片为主（温漂可补偿、线性好、成本低）。

惠斯通电桥：四臂电阻，输出为不平衡电压。单臂贴片（1/4 桥）时输出（\(\Delta R \ll R\) 线性化）：

\[ U_{out} \approx \frac{U_{ex}}{4}\, K\,\varepsilon \]

把应变片成对推挽贴（一拉一压）在相邻/相对臂上，输出翻倍/翻四倍，且温度引起的共模电阻变化在桥内自动抵消（温度自补偿的物理来源）：

关键结论：满量程信号只有几 mV，所以力传感器的信号链（激励源精度、仪用放大器、屏蔽）就是它的生命线。

4.2 弹性体与六维解耦

弹性体设计是结构力学与灵敏度的折中：越软形变越大、信号越大，但刚度下降 → 固有频率 \(\omega_n = \sqrt{k/m}\) 下降 → 力控可用带宽下降（力位混合控制第12节的接触共振），且抗冲击弱。常见结构：轮辐式（径向梁布置，低矮、抗扭，六维力主流）、马尔他十字（三梁/四梁）、S 型（单维拉压力）、平行四边形梁（位移传感器用）。

六维解耦的来历：弹性体上布 6~8 组应变桥，得到电压向量 \(\boldsymbol{V} \in \mathbb{R}^{6\sim8}\)。标定时对每个轴 \(j\) 施加已知力 \(\boldsymbol{F}_j\)，记录 \(\boldsymbol{V}_j\)，解出常量标定矩阵：

\[ \boldsymbol{F} = \mathbf{C}\,\boldsymbol{V}, \qquad \mathbf{C} = \boldsymbol{F}_{\text{load}}\,\boldsymbol{V}_{\text{meas}}^{+}\ (\text{伪逆}) \]

由于梁的几何误差与贴片位置偏差，\(\boldsymbol{V}\) 中各维互相串扰（加 \(F_x\) 时 \(M_y\) 桥也有输出）——\(\mathbf{C}\) 的非对角项就是解耦项，这是六维力传感器与”六个独立称重传感器”的本质区别，也是各家工艺差距所在（好的设计耦合 <3%）。

4.3 压电式与信号链

压电式（Kistler 路线）：石英/压电陶瓷受力产生电荷 \(Q = d \cdot F\)，经电荷放大器转电压。特色：刚度极高 → 固有频率可达数十 kHz，测冲击/振动的带宽碾压应变式；但电荷会缓慢泄漏（放大器输入阻抗非无穷），分钟级静态测量就漂没了——所以它是动态力专家，不能当恒力传感器用。

信号链（应变式）：精密基准激励源 → 电桥 → 仪用放大器（高共模抑制）→ 抗混叠滤波 → 24bit ΣΔ ADC。工程要点：桥压的温漂与噪声直接乘进输出（激励源要用电压基准而非电源）；六线制接法（sense 线回读桥压）消除长线压降误差；上电预热几分钟再采零点。

指标体系（选型按此顺序核对）：量程 → 分辨率（典型 1/4000~1/65000 FS）→ 重复性（比线性度更重要，重复性差无法软件补偿）→ 线性度/滞后（弹性体摩擦与预紧产生）→ 刚度/固有频率（决定控制带宽上限）→ 温漂与蠕变 → 过载保护（碰撞冲击常达 10 倍量程，机械限位比规格书上的”允许过载”更可信）。

4.4 六维力使用要点

  • 安装在腕部（末端工具前）：测工具与环境接触力；安装在基座（与桌面之间）：整机受力，腿式机器人也装足端
  • 必须做重力/惯性补偿：工具自身重量与运动惯性都会混入读数，\(\boldsymbol{F}_{\text{ext}} = \boldsymbol{F}_{\text{raw}} - \boldsymbol{F}_{\text{tool}}(\boldsymbol{q},\dot{\boldsymbol{q}},\ddot{\boldsymbol{q}})\)（力位混合控制第13节）
  • EtherCAT 集成版直接走总线（EL/AI 端子方案见EtherCAT 篇）

5. 视觉传感器

5.1 成像物理：CMOS 像元、快门与噪声

每个像元 = 光电二极管 + 电荷存储。光照产生光电流，在曝光时间内积累为电荷包（势阱），读出时转移为电压。三个决定画质的物理量：

  • 量子效率（QE）：入射光子 → 电子的转换率（峰值 40%~80%，随波长变化——看 QE 曲线选相机，不看”像素数”）
  • 满阱容量：势阱能存多少电子，决定单帧动态范围上限
  • 噪声三件套：散粒噪声（光子到达的泊松统计，\(\sqrt{N}\)，物理下限，无法消除）、读出噪声（电子学，工业相机 1~5 e⁻）、暗电流（热生电荷，温度每升约 6°C 翻倍——长曝光与高温场景要关注）
\[ \mathrm{SNR} = \frac{N_{sig}}{\sqrt{N_{sig} + N_{dark} + \sigma_{read}^2}} \]

卷帘 vs 全局快门的电路本质：卷帘逐行复位、逐行读出（每行曝光时刻不同 → 运动物体剪切变形，特征匹配/SLAM 直接歪掉）；全局快门每像元加一个采样保持电容，全部像元同时冻结再统一读出——多一层晶体管，填充因子降、成本高，但机器人运动场景没有商量余地，必须全局快门。

5.2 双目立体：视差几何与误差传播

深度-视差关系（相似三角形，\(f_x\) 为像素焦距、\(B\) 为基线、\(d\) 为视差）：

\[ Z = \frac{f_x\, B}{d} \]

对 \(d\) 求导得误差传播律——深度误差随距离平方增长：

\[ \delta Z = \frac{Z^2}{f_x\, B}\,\delta d \]

两个工程结论直接从公式读出：基线加倍 → 远距误差减半（D435 基线 50mm 近距灵活、D455 基线 95mm 专为远距与 VIO 设计）；但基线加长近距视差溢出（最小量程变大）、体积增大。主动红外散斑解决的是无纹理表面（白墙）无特征可匹配的问题；代价是户外阳光的红外底噪淹没散斑。匹配算法从经典 SGBM 到学习法（RAFT-Stereo）一直在进步，但 \(Z=f_xB/d\) 的几何约束不变。

5.3 结构光：投影编码 + 三角测量

投射已知编码图案，从图案变形反解深度：投影器与相机构成基线，深度精度同样服从三角测量几何。编码策略两代：时序编码（Gray 码序列逐位投影解码，精度最高但要投几十帧——工业扫描仪路线）与空间编码（一帧内散斑/条纹唯一可辨识——Kinect v1/奥比中光 Astra 路线，实时但用空间分辨率换编码冗余）。特性：近距（0.2~2m）毫米级精度、弱光友好；强环境光下信噪比崩、多机同场互相干扰（可用散斑图案区分缓解）。

5.4 ToF：相位法与飞行时间

iToF（间接法）：发射正弦调制红外光，测返回波与发射波的相位差：

\[ \Phi = \frac{4\pi f_{mod}\, d}{c} \;\Longrightarrow\; d = \frac{c\,\Phi}{4\pi f_{mod}} \]

调制频率决定模糊距离（\(d_{amb} = c/2f_{mod}\)：20 MHz → 7.5 m），多频调制解模糊；误差主源是多径干扰（墙角、镜面把光弹来弹去，相位混叠出”幽灵深度”）。dToF（直接法）：SPAD 单光子探测器 + TDC 时间数字转换，逐光子测往返时间（激光雷达同源），背景光鲁棒、像素稀疏。代表 Orbbec Femto Bolt（接棒 Azure Kinect，ToF 深度 + 人体骨架 SDK 生态，人形机器人头部常客）。

5.5 事件相机：异步像素的物理学

像元电路 = 对数光感受器 + 差分比较器：亮度变化超过阈值（ON/OFF 极性）时，该像素独立发出一个事件 \((x, y, t, \text{pol})\)，不等帧、不等邻居。物理上带来三个量级优势：时间分辨率 µs 级（无曝光时间概念）、动态范围 120dB+（对数响应天然压缩）、数据稀疏（静止场景零输出，带宽与算力自适应场景运动量）。代价：静止纹理”消失”、算法生态需要事件版本（光流/SLAM 均要重写），与帧相机混合（iniVation DAVIS：帧+事件同像素）是过渡期的务实选择。代表：Prophesee EVK4（Sony IMX636，1280×720，µs 级时间戳）、iniVation DAVIS342。

5.7 使用要点

内参标定（棋盘格）与手眼标定是入场券——完整的针孔/畸变模型、张正友标定与 AX=XB 手眼标定推导见相机及标定专题篇；多相机系统用硬件触发同步（Genlock/触发线），软件时间戳对不齐运动场景。

6. 激光雷达（LiDAR）

6.1 原理

测距核心是 ToF：发射脉冲/调制波，测往返时间（脉冲式）或相位差（调幅连续波）。按扫描机构分：

  • 机械旋转：电机带动多线束旋转，360° 水平视场，点云密、寿命受限于转轴
  • MEMS/转镜半固态：微镜摆动扫描，无整机旋转、车规友好
  • 纯固态（Flash/OPA）：面阵发射或光学相控阵，无运动部件——机器人朝这个方向迁移

6.2 机器人选型要点

  • 视场角：头部 SLAM 要 360°（Mid-360 类），臂上避障用小视场固态即可
  • 盲区（最小量程）与抗串扰（多机同场）、点云噪声模型（SLAM 前端要喂）
  • 安全认证：人机协作区域的安全激光雷达要 PL d 级认证（SICK 安全系列）
  • 二维单线（思岚 RPLIDAR）够扫地机与轻量 SLAM；腿式/人形主流是 Mid-360 档

8. 定位与导航辅助

  • GNSS/RTK：卫星定位 + 基站差分改正，厘米级。室外 AGV/无人机标配。代表：u-blox ZED-F9P（接收机标杆）、和芯星通 UM980（国产板卡）、千寻位置（RTK 差分服务）、华测/天宝（组合导航整机）。注意城市峡谷/树荫下的多路径失效——必须与 IMU/激光组合
  • UWB：超宽带脉冲到达时间差，室内 10~30cm 定位，机器人间相对定位（多机编队）也靠它。代表：Qorvo/Decawave DW3000 芯片方案、清研讯科
  • AGV 传统导航：磁条（磁导航传感器）、二维码（地面 QR 码 + 顶置相机，仓储 AGV 主流）、反射板激光导航（SICK NAV 系列）——新建项目多转向自然导航（SLAM）
  • 室内”GPS”替代：动作捕捉（OptiTrack/Vicon，室内科研定位真值）、视觉标记（AprilTag，[通讯与视觉]系统的胶水）

10. 选型方法论与系统级问题

按控制层级倒推带宽：电流环 kHz 级（电流传感器）、关节环 0.51kHz（编码器/力矩）、整机身姿环 200500Hz（IMU）、任务/感知层 1060Hz（视觉/激光）——**传感器带宽必须覆盖所在环的 510 倍**。

接口与数据链路：芯片级 SPI/I2C（板内，串口篇I2C/SPI 节）、模块级 CAN/CAN-FD（驱动器侧）、整机级 EtherCAT（EL 端子接入所有模拟/编码器信号，EtherCAT 篇）。

时间同步：多传感器融合的第一杀手。手段按强度：硬件触发线 > PTP/PTP-like（如相机 IEEE1588）> 软件时间戳对齐（最后的选择）。相机与 IMU 不同步 10ms，VIO 就废了。

标定链：单相机内参 → 手眼（相机↔法兰）→ 多传感器外参（雷达↔相机↔IMU）→ 力传感器零点（上电静置采均值）。每次结构改动都要重标——把标定程序做成脚本放进仓库（Python 规范的”运行留指纹”习惯）。

采购务实建议：科研原型按”事实标准”买（ATI 的 F/T、RealSense 的深度、Mid-360 的雷达、Xsens 的 IMU）——社区工具链兼容性值回差价；量产阶段再国产替代（坤维/奥比中光/禾赛/速腾供应链成熟）。

11. 总结

传感器 一句话 事实标准
编码器 关节的眼睛；增量四倍频、绝对格雷码、双编码消传动误差 Heidenhain/多摩川/AS5047P
IMU 加速度计低频准 + 陀螺高频准 → 融合 BMI088 → Xsens MTi
六维力 弹性体+应变片+解耦矩阵；重力补偿是入场券 ATI Nano17
触觉 压阻阵列/视触觉/三轴 MEMS 三路线 GelSight/帕西尼
视觉 主动双目通吃室内；全局快门是底线 RealSense D435/OAK-D
激光雷达 机械 360° → 固态化；视场与盲区定生死 Livox Mid-360
短距离 超声补视觉盲区、ToF 精密、毫米波全天候 VL53L1X/IWR6843
定位 RTK 管室外、UWB 管室内、都要与 IMU 联姻 ZED-F9P/DW3000

传感器系统的成熟度标志不是”买了多贵的传感器”，而是标定链完整、时间同步可靠、每个传感器的噪声模型心里有数——这三件事做扎实，便宜的传感器也能撑起高性能机器人；反之亦然。
