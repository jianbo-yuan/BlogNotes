机器人力位混合控制算法

力位混合控制 阻抗控制 导纳控制 操作空间 李雅普诺夫稳定性 力控制 机器人控制 Python仿真
机器人理论与技术 机器人学理论基础
发布日期:   2026-08-30

位置控制把”走哪条轨迹”做到极致，但一碰上接触任务就露出短板：往桌面上写字，笔尖多走 0.1mm，要么笔悬空、要么戳穿纸——位置误差在接触方向上被环境放大成巨大的接触力。接触任务的正确提法是：沿约束面的法向控力、沿切向控位置。力位混合控制（hybrid force/position control）就是把任务空间的 6 个自由度切成两半、分别用力环和位置环去管的控制框架。

本文是”理论 + 实现”的完整版：先沿”约束建模 → 力/运动对偶 → 经典混合控制 → 操作空间动力学前馈 → 阻抗/导纳 → 稳定性”的主线把理论推透，再给出五个控制模型的完整数学推导与实测可运行的 Python 实现（PD + 重力补偿、计算力矩、阻抗、导纳、力位混合），全部代码只依赖 numpy，文中数值全部来自真实运行。衔接运动学基础（雅可比）与动力学基础（\(\mathbf{M}, \mathbf{C}, \boldsymbol{g}\) 与 \(\boldsymbol{\tau} = \mathbf{J}^{\top}\boldsymbol{F}\) 的对偶）。

1. 接触任务为什么位置控制会失败

三个典型场景：

任务 位置控制的问题
恒力打磨 法向位置误差 ±0.05mm，刚度 10⁵ N/m 的表面 → 法向力波动 ±50N，工件烧糊或飞出
轴孔装配（peg-in-hole） 任何微小姿态误差都变成卡死与巨大侧向力，无从”顺从”
抓握易碎品 指端位置定的太”死”，工件尺寸误差直接转化为捏碎力

共同本质：环境构成了约束，约束方向上位置不可独立规划——机器人决定不了沿法向走多远（表面说了算），只能决定压多大力。反过来，切向方向上力不可独立规划（无摩擦理想表面不提供切向支撑），只能规划速度。于是一个接触任务天然分解成两组正交的自由度：一半控力、一半控位置。

本文所有实现共用一个仿真平台：二连杆平面臂（动力学基础第6节手推过的闭式动力学）+ 一堵刚性墙。五个控制模型按”需要多少模型信息”递进，先看实测结果总表（后文逐个推导）：

① PD + 重力补偿 仅 \(\boldsymbol{g}(\boldsymbol{q})\) 否 定点误差 \(1.1\times10^{-14}\) rad
② 计算力矩（反馈线性化） 全模型 \(\mathbf{M}, \mathbf{C}, \boldsymbol{g}\) 否 正弦跟踪 \(2.3\times10^{-4}\) rad；+20% 惯量误差仍 \(6.0\times10^{-4}\)

3. 前置控制器①：PD + 重力补偿——最简单的渐近稳定

3.1 推导

取关节空间控制律（\(\boldsymbol{e} = \boldsymbol{q}_d - \boldsymbol{q}\)）：

\[ \boldsymbol{\tau} = \mathbf{K}_p\boldsymbol{e} - \mathbf{K}_d\dot{\boldsymbol{q}} + \boldsymbol{g}(\boldsymbol{q}) \]

代入动力学 \(\mathbf{M}\ddot{\boldsymbol{q}} + \mathbf{C}\dot{\boldsymbol{q}} + \boldsymbol{g} = \boldsymbol{\tau}\)，重力项精确抵消：

\[ \mathbf{M}(\boldsymbol{q})\ddot{\boldsymbol{q}} + \mathbf{C}(\boldsymbol{q},\dot{\boldsymbol{q}})\dot{\boldsymbol{q}} = \mathbf{K}_p\boldsymbol{e} - \mathbf{K}_d\dot{\boldsymbol{q}} \]

李雅普诺夫证明全局渐近稳定。取能量型候选函数（动能 + “弹簧”势能）：

\[ V = \tfrac{1}{2}\dot{\boldsymbol{q}}^{\top}\mathbf{M}\dot{\boldsymbol{q}} + \tfrac{1}{2}\boldsymbol{e}^{\top}\mathbf{K}_p\boldsymbol{e} \]

沿轨迹求导（注意 \(\dot{\boldsymbol{e}} = -\dot{\boldsymbol{q}}\)）：

\[ \dot{V} = \dot{\boldsymbol{q}}^{\top}\!\left(\mathbf{M}\ddot{\boldsymbol{q}} + \tfrac{1}{2}\dot{\mathbf{M}}\dot{\boldsymbol{q}}\right) - \dot{\boldsymbol{q}}^{\top}\mathbf{K}_p\boldsymbol{e} \]

代入闭环的 \(\mathbf{M}\ddot{\boldsymbol{q}}\)：

\[ \dot{V} = \dot{\boldsymbol{q}}^{\top}\!\left(\mathbf{K}_p\boldsymbol{e} - \mathbf{K}_d\dot{\boldsymbol{q}} - \mathbf{C}\dot{\boldsymbol{q}} + \tfrac{1}{2}\dot{\mathbf{M}}\dot{\boldsymbol{q}}\right) - \dot{\boldsymbol{q}}^{\top}\mathbf{K}_p\boldsymbol{e} = -\dot{\boldsymbol{q}}^{\top}\mathbf{K}_d\dot{\boldsymbol{q}} + \dot{\boldsymbol{q}}^{\top}\underbrace{\left(\tfrac{1}{2}\dot{\mathbf{M}} - \mathbf{C}\right)}_{\text{反对称！}}\dot{\boldsymbol{q}} \]

用到动力学基础第9节的反对称性质 \(\left(\tfrac{1}{2}\dot{\mathbf{M}} - \mathbf{C}\right)^{\top} = -\left(\tfrac{1}{2}\dot{\mathbf{M}} - \mathbf{C}\right)\)：二次型 \(\dot{\boldsymbol{q}}^{\top}(\cdot)\dot{\boldsymbol{q}} = 0\) 恒成立，于是：

\[ \boxed{\dot{V} = -\dot{\boldsymbol{q}}^{\top}\mathbf{K}_d\dot{\boldsymbol{q}} \le 0} \]

\(\dot V = 0 \Rightarrow \dot{\boldsymbol{q}} = 0\)，由 LaSalle 不变性原理，最大不变集上闭环退化为 \(\mathbf{K}_p\boldsymbol{e} = 0 \Rightarrow \boldsymbol{e} = 0\)——全局渐近收敛到目标点。这条证明是机器人控制的”Hello World”：反对称性正是为它而存在。

3.2 代码与实测

注意若去掉重力补偿项，稳态误差 \(\boldsymbol{e}_\infty = \mathbf{K}_p^{-1}\boldsymbol{g}(\boldsymbol{q})\)（力平衡残留）——这就是”为什么关节 PD 必须配重力前馈”的定量答案。

4. 前置控制器②：计算力矩控制——反馈线性化

4.1 推导

PD 的问题：闭环仍是耦合非线性系统（\(\mathbf{M}(\boldsymbol{q})\)、\(\mathbf{C}\) 在环内），增益没有统一物理意义。计算力矩控制用模型把非线性在环内抵消掉：

\[ \boldsymbol{\tau} = \mathbf{M}(\boldsymbol{q})\big(\ddot{\boldsymbol{q}}_d + \mathbf{K}_d\dot{\boldsymbol{e}} + \mathbf{K}_p\boldsymbol{e}\big) + \mathbf{C}\dot{\boldsymbol{q}} + \boldsymbol{g} \]

代入动力学，\(\mathbf{M}\) 可逆、\(\mathbf{C}, \boldsymbol{g}\) 精确对消：

\[ \ddot{\boldsymbol{q}} = \ddot{\boldsymbol{q}}_d + \mathbf{K}_d\dot{\boldsymbol{e}} + \mathbf{K}_p\boldsymbol{e} \;\;\Longrightarrow\;\; \boxed{\;\ddot{\boldsymbol{e}} + \mathbf{K}_d\dot{\boldsymbol{e}} + \mathbf{K}_p\boldsymbol{e} = 0\;} \]

每个关节的误差动态是独立的线性二阶系统——这就是反馈线性化。增益直接按二阶系统标准形式配极点：\(\mathbf{K}_p = \omega_n^2\mathbf{I},\ \mathbf{K}_d = 2\zeta\omega_n\mathbf{I}\)（\(\zeta\) 常取 0.9~1）。

模型失配分析（实际必然失配）。设估计 \(\hat{\mathbf{M}} = (1+\delta)\mathbf{M}\)：

\[ \ddot{\boldsymbol{e}} + (1+\delta)\mathbf{K}_d\dot{\boldsymbol{e}} + (1+\delta)\mathbf{K}_p\boldsymbol{e} = -\delta\,\ddot{\boldsymbol{q}}_d \]

失配后误差动态仍是线性系统，只是增益缩放、多了有界激励项——误差有界、量级 \(\propto \delta\|\ddot{\boldsymbol{q}}_d\|/\omega_n^2\)，残差由外环 PID 或自适应律兜底。

4.2 代码与实测

5. 约束建模：自然约束与人工约束

Mason（1981）的表述把接触任务形式化。为任务选一个约束坐标系 {C}（通常：\(z_c\) 沿表面法向，\(x_c, y_c\) 沿切向），把末端速度 \(\boldsymbol{v} = [\dot{x}, \dot{y}, \dot{z}, \omega_x, \omega_y, \omega_z]^{\top}\) 与力旋量 \(\boldsymbol{F} = [f_x, f_y, f_z, n_x, n_y, n_z]^{\top}\) 排成 6 维：

  • 自然约束（natural constraints）：环境几何强加的、机器人不可违背的关系。对理想刚性光滑平面（\(z\) 法向）：
\[ \dot{z} = 0,\quad \omega_x = 0,\quad \omega_y = 0 \qquad\text{（运动学：贴面则不能法向移动、不能翘转）} \]
\[ f_x = 0,\quad f_y = 0,\quad n_z = 0 \qquad\text{（力学：光滑面不提供切向力与绕法向力矩）} \]
  • 人工约束（artificial constraints）：设计者选择去控制的量——恰好是自然约束的对偶补集：
方向 自然约束（环境定） 人工约束（我们控） 控什么
\(x, y\)（切向） \(f_x = f_y = 0\) \(\dot{x}_d, \dot{y}_d\) 速度/位置
\(z\)（法向） \(\dot{z} = 0\) \(f_{z,d}\) 力
\(\omega_z\) \(n_z = 0\) \(\omega_{z,d}\) 速度
\(\omega_x, \omega_y\) \(\dot\omega_x = \dot\omega_y = 0\) \(n_{x,d}, n_{y,d}\) 力矩

6 个自由度被严格二分，每组 3 个。写成矩阵就是选择矩阵：

\[ \mathbf{S} = \mathrm{diag}(\sigma_1, \dots, \sigma_6), \quad \sigma_i \in \{0, 1\} \qquad \mathbf{S}\text{ 选位置方向}，\ \mathbf{I}-\mathbf{S}\text{ 选力方向} \]

上例中 \(\mathbf{S} = \mathrm{diag}(1,1,0,1,0,0)\)。注意自然约束与人工约束逐项互补——不可在同一个方向既控位置又控力（那是阻抗控制的思路，见第9节）。

6. 力与运动的对偶：雅可比把两个世界连起来

任务空间与关节空间通过雅可比 \(\mathbf{J}(\boldsymbol{q}) \in \mathbb{R}^{6\times n}\) 互映，且速度映射与力映射互为转置：

\[ \text{速度：}\ \boldsymbol{v} = \mathbf{J}\dot{\boldsymbol{q}} \qquad\Longleftrightarrow\qquad \text{力：}\ \boldsymbol{\tau} = \mathbf{J}^{\top}\boldsymbol{F} \]

这条对偶（虚功原理）意味着：任务空间的 6 维力旋量指令，不需要”逆雅可比”，直接一次 \(\mathbf{J}^{\top}\) 乘法就落到关节力矩上——这是力控制比位置控制”便宜”的地方。奇异性的语义也随之翻转：\(\mathbf{J}\) 奇异 = 末端某方向不可动 = 该方向可以输出任意大力矩而关节力矩有限——力控反而在奇异附近友好。

约束系 {C} 下的量要旋转过来：设 \(\mathbf{R}_c\) 为 {C} 相对末端系的姿态，构造 6 维旋转块阵

\[ \mathbf{T}_c = \begin{bmatrix} \mathbf{R}_c & \mathbf{0} \\ \mathbf{0} & \mathbf{R}_c \end{bmatrix}, \qquad \mathbf{J}_c = \mathbf{T}_c\, \mathbf{J}, \qquad \boldsymbol{F}_c = \mathbf{T}_c\, \boldsymbol{F} \]

选择矩阵永远作用在 \(\mathbf{J}_c\) 表达的约束系上——坐标系管理错乱是力控实现的头号 bug 源（见第13节）。

7. 经典混合控制：Raibert–Craig 结构

Raibert 与 Craig（1981）给出第一版完整结构：位置误差经 \(\mathbf{S}\) 投影进位置环，力误差经 \(\mathbf{I}-\mathbf{S}\) 投影进力环，两环输出在任务空间相加。

控制律（任务空间 PD + PI 形式）：

\[ \boldsymbol{F}_{\text{cmd}} = \underbrace{\mathbf{S}\left(\mathbf{K}_p\tilde{\mathbf{x}} + \mathbf{K}_d\dot{\tilde{\mathbf{x}}}\right)}_{\text{位置子空间}} + \underbrace{(\mathbf{I}-\mathbf{S})\left(\boldsymbol{F}_d + \mathbf{K}_{fp}\tilde{\boldsymbol{F}} + \mathbf{K}_{fi}\!\int\!\tilde{\boldsymbol{F}}\,dt - \mathbf{K}_{fv}\dot{\mathbf{x}}\right)}_{\text{力子空间}} + \underbrace{\hat{\boldsymbol{g}}_{\text{task}}}_{\text{重力补偿}} \]

关节力矩 \(\boldsymbol{\tau} = \mathbf{J}_c^{\top}\boldsymbol{F}_{\text{cmd}} + \boldsymbol{g}(\boldsymbol{q})\)。三个工程要点：

  • 力方向上的速度阻尼项 \(-\mathbf{K}_{fv}\dot{\mathbf{x}}\) 不可省：纯 PI 力环贴着刚性表面几乎必然振荡（见第12节），阻尼项就是力环的”稳定器”——第11节的实测将给出定量证明（去掉它力波动放大 325 倍）
  • 期望位置只在位置子空间有意义（\(\mathbf{S}\) 把法向位置误差滤掉——否则表面高度差会通过位置环灌进力环）
  • 力积分项要加抗饱和：接触丢失（\(\tilde{\boldsymbol{F}}\) 突变）时立即清零积分，否则重新接触瞬间是一记”锤击”

Raibert–Craig 原始版本在关节空间做投影、忽略动力学耦合——当位置子空间大加速度运动时，惯性力会”漏”进力子空间污染接触力。修正它的自然路径就是把动力学基础里的 \(\mathbf{M}, \mathbf{C}, \boldsymbol{g}\) 前馈进来。

8. 操作空间方法：动力学前馈的混合控制（Khatib 形式）

Khatib（1987）的操作空间（operational space）表述把混合控制升级为动力学一致版本。先在任务空间定义操作空间惯量阵：

\[ \boldsymbol{\Lambda}(\boldsymbol{q}) = \left(\mathbf{J}_c\,\mathbf{M}^{-1}\mathbf{J}_c^{\top}\right)^{-1} \]

及其偏置项（任务空间的科氏/离心/重力，\(\bar{\mathbf{J}} = \mathbf{M}^{-1}\mathbf{J}_c^{\top}\boldsymbol{\Lambda}\) 为动力学一致逆）：

\[ \boldsymbol{\mu} + \boldsymbol{p} = \bar{\mathbf{J}}^{\top}\!\left(\mathbf{C}\dot{\boldsymbol{q}} + \boldsymbol{g}\right) - \boldsymbol{\Lambda}\,\dot{\mathbf{J}}_c\dot{\boldsymbol{q}} \]

任务空间动力学于是有了与关节空间 \(\mathbf{M}\ddot{\boldsymbol{q}} + \mathbf{C}\dot{\boldsymbol{q}} + \boldsymbol{g} = \boldsymbol{\tau}\) 完全同形的样子：

\[ \boldsymbol{\Lambda}\ddot{\mathbf{x}}_c + \boldsymbol{\mu} + \boldsymbol{p} = \boldsymbol{F} \]

混合控制律直接照抄计算力矩控制（第4节）的配方，只是按 \(\mathbf{S}\) 分两半：

\[ \boldsymbol{F}_{\text{cmd}} = \mathbf{S}\Big(\boldsymbol{\Lambda}\big(\ddot{\mathbf{x}}_{c,d} + \mathbf{K}_d\dot{\tilde{\mathbf{x}}}_c + \mathbf{K}_p\tilde{\mathbf{x}}_c\big) + \boldsymbol{\mu} + \boldsymbol{p}\Big) + (\mathbf{I}-\mathbf{S})\Big(\boldsymbol{F}_d + \mathbf{K}_{fp}\tilde{\boldsymbol{F}} - \mathbf{K}_{fv}\dot{\mathbf{x}}_c\Big) \]
\[ \boldsymbol{\tau} = \mathbf{J}_c^{\top}\boldsymbol{F}_{\text{cmd}} \]

这个形式的好处全来自 \(\boldsymbol{\Lambda}\) 前馈：位置子空间的大加速度运动不再通过惯性耦合漏进力子空间；增益 \(\mathbf{K}_p, \mathbf{K}_d\) 是任务空间的 PD，物理意义明确（期望末端刚度和阻尼），随构型变化保持一致。\(\bar{\mathbf{J}}\) 的”动力学一致”性质保证力指令映射到关节时不引入任务空间之外的冗余运动激励。冗余自由度（\(n > 6\)）时还可叠加零空间姿态控制：\(\boldsymbol{\tau}_{\text{null}} = \left(\mathbf{I} - \mathbf{J}_c^{\top}\bar{\mathbf{J}}^{\top}\right)\boldsymbol{\tau}_0\)，不干扰主任务。

9. 阻抗控制：把”柔顺”设计进闭环

混合控制要求约束几何已知；当接触/脱离频繁、方向不确定时，更稳的思路是阻抗控制（Hogan）：不直接控力或位置，而是设计末端的机械阻抗——无论环境怎么推，末端都表现为一个可设计的弹簧-质量-阻尼系统。

9.1 推导

目标闭环：

\[ \mathbf{M}_d\ddot{\tilde{\mathbf{x}}} + \mathbf{B}_d\dot{\tilde{\mathbf{x}}} + \mathbf{K}_d\tilde{\mathbf{x}} = \boldsymbol{F}_{\text{ext}}, \qquad \tilde{\mathbf{x}} = \mathbf{x} - \mathbf{x}_d \]

三步从关节动力学构造出来。

第一步：任务空间动力学。控制结构为 \(\boldsymbol{\tau} = \mathbf{J}^{\top}\boldsymbol{F}_{\text{cmd}} + \mathbf{C}\dot{\boldsymbol{q}} + \boldsymbol{g}\)（偏置在关节空间补掉），代入 \(\mathbf{M}\ddot{\boldsymbol{q}} + \mathbf{C}\dot{\boldsymbol{q}} + \boldsymbol{g} = \boldsymbol{\tau} + \mathbf{J}^{\top}\boldsymbol{F}_{\text{ext}}\)：

\[ \mathbf{M}\ddot{\boldsymbol{q}} = \mathbf{J}^{\top}(\boldsymbol{F}_{\text{cmd}} + \boldsymbol{F}_{\text{ext}}) \]

左乘 \(\mathbf{J}\mathbf{M}^{-1}\) 并加上 \(\dot{\mathbf{J}}\dot{\boldsymbol{q}}\)（凑出 \(\ddot{\mathbf{x}} = \mathbf{J}\ddot{\boldsymbol{q}} + \dot{\mathbf{J}}\dot{\boldsymbol{q}}\)）：

\[ \ddot{\mathbf{x}} = \mathbf{J}\mathbf{M}^{-1}\mathbf{J}^{\top}(\boldsymbol{F}_{\text{cmd}} + \boldsymbol{F}_{\text{ext}}) + \dot{\mathbf{J}}\dot{\boldsymbol{q}} \]

定义操作空间惯量 \(\boldsymbol{\Lambda} = (\mathbf{J}\mathbf{M}^{-1}\mathbf{J}^{\top})^{-1}\)（第8节同一对象）：

\[ \boxed{\ \boldsymbol{\Lambda}(\ddot{\mathbf{x}} - \dot{\mathbf{J}}\dot{\boldsymbol{q}}) = \boldsymbol{F}_{\text{cmd}} + \boldsymbol{F}_{\text{ext}}\ } \]

第二步：构造控制律。解出想要的 \(\ddot{\mathbf{x}}\)（由期望阻抗方程反解）并塞进去：

\[ \ddot{\mathbf{x}}_{\text{ref}} = \ddot{\mathbf{x}}_d + \mathbf{M}_d^{-1}\big(\boldsymbol{F}_{\text{ext}} - \mathbf{B}_d\dot{\tilde{\mathbf{x}}} - \mathbf{K}_d\tilde{\mathbf{x}}\big) \]
\[ \boldsymbol{F}_{\text{cmd}} = \boldsymbol{\Lambda}(\ddot{\mathbf{x}}_{\text{ref}} - \dot{\mathbf{J}}\dot{\boldsymbol{q}}) - \boldsymbol{F}_{\text{ext}} \]

（\(\boldsymbol{F}_{\text{ext}}\) 由力传感器给出。）

第三步：代回验证。\(\boldsymbol{\Lambda}(\ddot{\mathbf{x}} - \dot{\mathbf{J}}\dot{\boldsymbol{q}}) = \boldsymbol{\Lambda}(\ddot{\mathbf{x}}_{\text{ref}} - \dot{\mathbf{J}}\dot{\boldsymbol{q}})\) ⟹ \(\ddot{\mathbf{x}} = \ddot{\mathbf{x}}_{\text{ref}}\)，代回第一步的参考式：

\[ \ddot{\mathbf{x}} - \ddot{\mathbf{x}}_d = \mathbf{M}_d^{-1}(\boldsymbol{F}_{\text{ext}} - \mathbf{B}_d\dot{\tilde{\mathbf{x}}} - \mathbf{K}_d\tilde{\mathbf{x}}) \;\Longrightarrow\; \boxed{\ \mathbf{M}_d\ddot{\tilde{\mathbf{x}}} + \mathbf{B}_d\dot{\tilde{\mathbf{x}}} + \mathbf{K}_d\tilde{\mathbf{x}} = \boldsymbol{F}_{\text{ext}}\ }\qquad\blacksquare \]

末端闭环精确等于设计出的二阶阻抗——刚度、阻尼、表观质量 \((\mathbf{K}_d, \mathbf{B}_d, \mathbf{M}_d)\) 全部是设计参数。

稳态接触力（弹簧串联公式）。命令轨迹把末端压进墙面 \(p_0\)（本 demo \(p_0 = 0.04\) m），稳态时：墙提供 \(F = K_w d\)，阻抗弹簧提供 \(F = K_d\tilde{x}\)，深度 \(d = p_0 - \tilde{x}\)，解出：

\[ F = \frac{p_0}{\dfrac{1}{K_w} + \dfrac{1}{K_d}} \qquad \text{（墙刚度与期望刚度串联后的等效刚度 } \times \text{ 压入深度）} \]

9.2 代码与实测

实测 31.50 N / 275.86 N，与串联公式理论值逐位一致——推导每一步正确性的最硬验证。期望刚度调软 10 倍，接触力降 8.8 倍，且不依赖任何力控积分。

10. 导纳控制：位置机器人的柔顺外环

阻抗控制要求底层是力矩接口。工业臂底层往往是刚性位置伺服（改不动），柔顺只能加在外环——导纳控制：测力，修正位置指令。

10.1 推导

\[ \text{外环（导纳滤波器）：}\quad \mathbf{M}_a\ddot{\mathbf{e}}_c + \mathbf{B}_a\dot{\mathbf{e}}_c + \mathbf{K}_a\mathbf{e}_c = \boldsymbol{F}_{\text{meas}}, \qquad \mathbf{x}_{\text{cmd}} = \mathbf{x}_d + \mathbf{e}_c \]
\[ \text{内环（刚性伺服）：}\quad \boldsymbol{\tau} = \mathbf{M}\,\mathbf{J}^{-1}\!\left(\ddot{\mathbf{x}}_{\text{ref}} - \dot{\mathbf{J}}\dot{\boldsymbol{q}}\right) + \mathbf{C}\dot{\boldsymbol{q}} + \boldsymbol{g},\quad \ddot{\mathbf{x}}_{\text{ref}} = k_p(\mathbf{x}_{\text{cmd}} - \mathbf{x}) - k_d\dot{\mathbf{x}} \]

内环增益取很高（demo 中等效刚度 \(2\times10^4\) N/m），近似 \(\mathbf{x} \approx \mathbf{x}_{\text{cmd}}\)。

稳态接触力：墙深 \(d = p_0 - e_{c,y}\)，力平衡 \(K_w d = K_a e_{c,y}\)，解出与阻抗控制同形的串联公式 \(F = p_0/(1/K_w + 1/K_a) = 39.2\) N（\(p_0=0.04\), \(K_a=1000\)）。对比纯位置基线（无导纳、同一压入轨迹、同一刚性内环）实测稳态力 683 N——导纳环把接触力压到 37.1 N（约 1/18），代价只是末端位置偏让约 3.7 cm。

10.3 四类框架怎么选型

框架 控制目标 需要力传感器 需要约束几何 典型场景
纯位置控制 轨迹跟踪 否 — 自由空间
阻抗控制（Hogan） 机械阻抗 \(\mathbf{Z} = \boldsymbol{\Lambda}s^2 + \mathbf{D}s + \mathbf{K}\) 可选 否 接触/非接触统一处理、过渡柔和
导纳控制 力测得→位置参考修正 需要 否 高刚度位置机器人（工业臂）+ 接触
力位混合 法向精确控力、切向精确轨迹 需要 是（约束系） 打磨、装配、抛光、恒力抓握

三条经验法则：

  1. 任务方向已知且稳定 → 混合控制：法向力精度直接由力环保证（±0.5N 量级）；阻抗控制的法向力是 \(K \cdot \Delta x\) 的间接结果，误差大
  2. 接触/脱离频繁、方向不确定 → 阻抗/导纳：混合控制在约束系突然变化（打滑、跳离表面）时会瞬间失配，阻抗控制天然平滑过渡
  3. 工程上常叠两层：导纳外环（慢，管交互柔顺）+ 内部位置/力混合环（快，管精度），工业协作臂多半是这种结构

阻抗 vs 导纳的镜像关系：阻抗是”力矩接口，机械阻抗可设计，适合低减速比直驱”；导纳是”位置接口，表观柔顺可设计，适合高刚度工业臂”。两者不能直接比好坏，接口形态决定选择。

11. 力位混合控制的完整 Python 实现

11.1 推导回顾与控制律

约束几何：水平墙面 \(y_w\)，法向 \(\hat{\mathbf{y}}\)，选择矩阵 \(\mathbf{S} = \mathrm{diag}(1, 0)\)：切向 \(x\) 控位置、法向 \(y\) 控力（第五、七节）。位置子空间沿用 \(\boldsymbol{\Lambda}\) 前馈 + PD；力子空间设期望接触反力 \(f_d\)（作用于机器人，\(+\hat{\mathbf{y}}\)）、传感器读数 \(f\)。先验平衡态：稳态时 \(\boldsymbol{F}_{\text{cmd}} + \boldsymbol{F}_{\text{ext}} = 0\)，要 \(f = f_d\) 必须命令 \(\boldsymbol{F}_{\text{cmd},y} = -f_d\)（向 \(-\hat{\mathbf{y}}\) 压）。加误差校正与阻尼：

\[ \boldsymbol{F}_{\text{frc}} = (\mathbf{I}-\mathbf{S})\begin{bmatrix} 0 \\ -\big(f_d + k_{fp}(f_d - f) + k_{fi}\!\int\!(f_d - f)\,dt\big) - k_{fv}\,\dot{y} \end{bmatrix} \]

逐项验证方向：欠压（\(f < f_d\)）⟹ 更向下压 ✓；过压则回撤 ✓；\(-k_{fv}\dot y\) 恒阻碍法向运动 ✓。积分项带抗饱和限幅。

11.2 代码与实测

两组实测的对照就是第7节”力方向速度阻尼不可省”的定量证明：去掉 \(k_{fv}\dot y\) 一项，力波动标准差从 ±0.01 N 恶化到 ±3.25 N（325 倍）——原因是刚性墙的接触共振（\(\sqrt{K_w/m_{\text{eff}}} \approx 350\) rad/s，见第12节）只有靠阻尼项压得住。均值 10.00 N 说明 P+I 通道无静差；切向 0.8 mm 说明位置子空间不受力子空间干扰（\(\boldsymbol{\Lambda}\) 前馈解耦有效）。

12. 稳定性专题：力控为什么容易振荡

力反馈环是所有控制环里最容易失稳的，物理根源是接触共振：末端等效质量 \(m_{\text{eff}}\) 压在环境刚度 \(K_e\) 上，构成弹簧-质量系统 \(\omega_n = \sqrt{K_e / m_{\text{eff}}}\)。钢对钢 \(K_e \sim 10^5\text{–}10^6\) N/m，\(\omega_n\) 轻松上 kHz——而力环带宽（受传感器滤波、采样、结构柔度限制）通常只有几十 Hz。相位滞后叠上去，就是一个待激发的振荡器。工程对策按优先级：

  1. 力方向的阻尼项（\(-\mathbf{K}_{fv}\dot{\mathbf{x}}\)，第7节）：消耗接触共振能量，最有效的一手
  2. 降 \(K_e\) 等效刚度：柔顺工具（缓冲垫、柔性腕），把 \(\omega_n\) 拉下来——打磨头装橡胶垫不是外行行为，是控制工程师行为
  3. 传感器滤波：截止频率取力环带宽 510 倍（典型 100500 Hz），对机械臂结构共振频率（典型 20~80 Hz）处加陷波；滤波再狠也别把相位滞后留在环内
  4. 增益纪律：力环带宽先保守（5~10 Hz），稳了再提；\(\mathbf{K}_{fp}\) 从小往大试，振荡征兆（接触力毛刺、嗡鸣）立即回退
  5. 冲击过渡（自由空间→接触瞬间）：接近段用阻抗模式/降速接近（<0.05 m/s），检测到接触后再切入力环——直接带力环全速撞上刚性表面，什么调参都救不了

采样率要求：位置环/导纳环 ≥ 500 Hz~1 kHz，力信号同步采样，控制周期抖动要小（实时线程，见C++ 规范实时专项）。

13. 实现要点清单

传感器与标定：

  • F/T 传感器装腕部（靠近末端，减少臂杆惯性污染）；末端工具的重力与惯性力先标定补偿：\(\boldsymbol{F}_{\text{ext}} = \boldsymbol{F}_{\text{raw}} - \boldsymbol{F}_{\text{tool}}(\boldsymbol{q}, \dot{\boldsymbol{q}}, \ddot{\boldsymbol{q}})\)——不补偿则手臂一加速，力环看到的全是自身惯性
  • 传感器系、工具系、约束系三套坐标系只用一个 \(\mathbf{T}_c\) 管理转换，全部旋转在一处代码完成

约束系管理：

  • 约束系可以是固定的（平面打磨），也可以随任务在线更新（曲面跟随：法向由视觉/点云/几何模型给出）；曲面情形把 \(\mathbf{R}_c\) 的更新频率与切向速度规划解耦
  • \(\mathbf{S}\) 矩阵允许”软切换”（0/1 改为 0~1 连续过渡）以缓和不连续

14. 典型应用形态

  • 恒力打磨/抛光：\(\mathbf{S}\) 法向控力（恒定 \(f_{z,d}\)，±0.5N 精度），切向控速度走网格轨迹；进给速度与法向力联合决定去除率，力环质量直接等于工艺质量
  • 轴孔装配：搜索阶段用螺旋搜索 + 力阈值检测；插入阶段混合控制——轴向控力、径向”顺从”（把径向等效刚度调低），配合倒角几何自对中
  • 灵巧手恒力抓握（与本站灵巧手综述的腱绳方案衔接）：指端法向力环维持目标握力（如 5N ± 0.2N），指间位置环维持包络形状；物体滑移由切向力/触觉检测触发力环增力——“捏多紧”是抓握稳定性的第一变量
  • 足式机器人足端：摆动腿是纯位置任务，支撑腿是力控任务（法向力分配由动力学的接触约束 KKT 系统求解），混合控制是双足/四足步态控制器的底层原语
  • 人机协作拖动：六维力传感器 + 导纳外环是”零力控制/拖动示教”的实现本质

15. 总结

五个控制器的关系演进链——按”需要多少模型信息”递进，一路通向力位混合：

\[ \underbrace{\text{①PD+重力}}_{\text{零模型}} \;\xrightarrow{\text{加前馈}}\; \underbrace{\text{②计算力矩}}_{\text{全模型，自由空间}} \;\xrightarrow{\text{换到任务空间}}\; \underbrace{\text{③阻抗}}_{\text{柔顺设计}} \;\xrightarrow{\text{外环化}}\; \underbrace{\text{④导纳}}_{\text{位置接口}} \;\xrightarrow{\text{子空间分解}}\; \underbrace{\text{⑤力位混合}}_{\text{接触任务终态}} \]

力位混合控制的完整逻辑链条：

\[ \underbrace{\text{环境几何}}_{\text{自然约束}} \Rightarrow \underbrace{\text{选择矩阵 } \mathbf{S}}_{\text{自由度二分}} \Rightarrow \underbrace{\mathbf{S}\text{ 位置环} + (\mathbf{I}-\mathbf{S})\text{ 力环}}_{\text{Raibert–Craig}} \Rightarrow \underbrace{\boldsymbol{\Lambda}\text{ 前馈}}_{\text{Khatib 动力学一致}} \Rightarrow \underbrace{\mathbf{J}^{\top}\text{ 落到关节}} \]
