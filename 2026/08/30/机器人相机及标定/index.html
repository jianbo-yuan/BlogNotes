机器人相机及标定

视觉感知 相机模型 手眼标定 相机标定
机器人理论与技术 机器人学理论基础
发布日期:   2026-08-30

视觉是机器人最富信息量的感知通道，也是数学链条最长的一条：从光的成像（相机模型）到几何的恢复（标定与三维重建）再到语义的理解（检测/分割/位姿估计）。本文按这条链展开：先总览机器人常用的视觉感知方法，再讲清各类相机的原理、优缺点与代表产品（与传感器篇的视觉一节互补，此处展开细节），然后进入本文重点——手眼标定：眼在手内（eye-in-hand）与眼在手外（eye-to-hand）两种构型的完整推导 + 实测通过的 Python 实现（Tsai-Lenz 求解器，两种构型合成数据误差 0.000mm）。

1. 机器人视觉感知方法总览

任务 方法族 代表算法/库 机器人应用
2D 检测/分割 CNN/Transformer YOLO 系列、RT-DETR、SAM2 工件识别、抓取候选、安全区域
6D 位姿估计 几何 PnP / 学习回归 EPnP+SolvePnP、PVNet、FoundationPose 抓取前的物体位姿（本领域的核心问题）
深度恢复 双目匹配 / 深度相机 SGBM、RAFT-Stereo 避障、抓取规划
点云处理 配准/分割/聚类 ICP、RANSAC 平面提取、DBSCAN（PCL/Open3D） 场景理解、桌面分割、工件定位
视觉 SLAM/里程计 特征/直接法 ORB-SLAM3、VINS-Fusion、RTAB-Map 移动机器人定位建图
视觉伺服 IBVS/PBVS ViSP 库 基于图像/位置的闭环控制

一条主线认识这些方法：像素 → 射线 → 三维点 → 位姿 → 语义标签。链条上每一环都依赖前一环的几何参数——这正是”标定”在视觉系统里的地位：模型不准，后面全歪。

2. 成像模型：内参、畸变、外参

针孔模型。三维点 \(\boldsymbol{P} = [X, Y, Z]^{\top}\)（相机系）投影到像素 \(\boldsymbol{p} = [u, v]^{\top}\)：

\[ s\begin{bmatrix} u \\ v \\ 1 \end{bmatrix} = \mathbf{K}\begin{bmatrix} \boldsymbol{R} & \boldsymbol{t} \end{bmatrix}\begin{bmatrix} \boldsymbol{P} \\ 1 \end{bmatrix}, \qquad \mathbf{K} = \begin{bmatrix} f_x & 0 & c_x \\ 0 & f_y & c_y \\ 0 & 0 & 1 \end{bmatrix} \]
  • 内参 \(\mathbf{K}\)：\(f_x, f_y\) 焦距（像素单位）、\((c_x, c_y)\) 光心——相机出厂后近似恒定，标定一次长期用
  • 外参 \([\boldsymbol{R}|\boldsymbol{t}]\)：世界系（或机器人系）到相机系的变换——每个安装都要重标，这就是手眼标定要解的东西
  • 单应的尺度模糊 \(s\)：单目丢深度，一切”从 2D 恢复 3D”的方法都在跟这个 \(s\) 作斗争

镜头畸变（标定的另一半）。径向畸变（桶形/枕形）+ 切向畸变：

\[ \begin{cases} x_d = x(1 + k_1 r^2 + k_2 r^4 + k_3 r^6) + 2p_1xy + p_2(r^2 + 2x^2) \\ y_d = y(1 + k_1 r^2 + k_2 r^4 + k_3 r^6) + p_1(r^2 + 2y^2) + 2p_2xy \end{cases} \]

广角/鱼眼镜头畸变大，OpenCV 要换 fisheye 模型；普通镜头 \(k_1, k_2, p_1, p_2\) 四参数够用。

3. 相机类型：原理、优缺点与代表产品

3.1 逐类拆解

① 单目工业相机（全局快门 CMOS）
原理：裸针孔模型，被动采光。优点：分辨率/帧率/感光度自由度最大、便宜、体积小。缺点：单帧无深度，尺度靠运动或先验恢复。产品：海康机器人 MV 系列、大恒图像、Basler ace、Teledyne FLIR——按”分辨率 × 帧率 × 传感器尺寸（感光度）× 快门类型”四项选。机器人运动场景必须全局快门，卷帘逐行曝光会让运动图像剪切变形。

② 主动红外双目
原理：两个普通相机 + 投射红外散斑纹理辅助立体匹配，视差 → 深度 \(Z = fB/d\)（基线 \(B\)、视差 \(d\)）。优点：抗无纹理表面（散斑补纹理）、被动部分可当普通双目、成本低。缺点：户外强红外（阳光）压制散斑；基线决定深度量程。产品：Intel RealSense D435（近距标杆）/D455（基线加长，远距与姿态估计）、Stereolabs ZED 2i、Luxonis OAK-D（板载推理，视觉+神经网络一体）。

③ 结构光
原理：投射已知编码图案（如散斑/条纹），三角测量逐点解深度。优点：近距（0.2~2m）精度最高、对无纹理物体友好。缺点：强环境光下图案被淹没、帧率低、多机互相干扰。产品：奥比中光 Orbbec Astra 系列（消费级物体的深度默认方案）。

④ ToF（飞行时间）
原理：发射调制红外光，测相位差（连续波）或往返时间（脉冲），SPAD/像素级测时。优点：整幅深度帧率高（30~60fps）、量程远（数米）、与纹理无关。缺点：多径反射（角落/镜面出错）、多机串扰、近距离精度不如结构光。产品：Orbbec Femto Bolt（接棒 Azure Kinect，Body SDK 人体骨架生态）、pmd 等。

⑤ 事件相机（动态视觉传感器）
原理：每个像素独立、异步地报告亮度变化（不输出整帧），达到微秒级时间分辨率与 120dB+ 动态范围。优点：高速运动/高对比光照场景无敌（挥动机械臂的追踪、高速避障）、数据稀疏省算力。缺点：静止场景无输出、算法生态年轻、与传统帧算法不兼容。产品：Prophesee（EVK4，Sony IMX636 传感器）、iniVation DAVIS342（帧+事件混合）。

⑥ 鱼眼/全景（概览）
超广角视场（>180°）配合 fisheye 畸变模型，用于导航避障的全景感知（AGV 四周一镜看全）。牺牲边缘分辨率换取视场。

4. 相机内参标定：张正友法与 OpenCV 实操

张正友法（1999，工业标准）：打印棋盘格贴平板，采集 ≥10 张不同姿态照片。每张图棋盘角点给出单应 \(\mathbf{H} = \mathbf{K}[\boldsymbol{r}_1\ \boldsymbol{r}_2\ \boldsymbol{t}]\)；每张单应对内参提供 2 个约束（\(\mathbf{H}\) 的列正交性），3 张以上即可闭式解出 \(\mathbf{K}\)，再联合优化畸变与所有外参。要点：姿态要多变（绕三个轴都转起来，纯平移采图会病态）、图像四角都要有角点分布。

5. 手眼标定：AX = XB 的两种构型

5.1 问题从哪来

相机看到的一切都表达在相机系里；机器人执行的一切都表达在基座系里（末端位姿由正运动学给出）。两者之间差一个固定变换，手眼标定就是把它测出来：

  • 眼在手内（eye-in-hand）：相机装在末端上。待求 \(\mathbf{X} = {}^{end}\mathbf{T}_{cam}\)（末端→相机）。相机跟着臂走，看的是固定环境
  • 眼在手外（eye-to-hand）：相机固定在外部（工作台/桁架上）。待求 \(\mathbf{Y} = {}^{base}\mathbf{T}_{cam}\)（基座→相机）。相机看的是随臂运动的末端

5.2 推导：殊途同归的 AX = XB

眼在手内。把标定板固定在工作台上。设 \(\mathbf{G}_i = {}^{base}\mathbf{T}_{end,i}\)（第 \(i\) 个采样的机器人正运动学）、\(\mathbf{C}_i = {}^{cam}\mathbf{T}_{board}\)（该姿态下相机看板的位姿，由 PnP 得到）。板不动，链式变换恒定：

\[ \mathbf{G}_i\, \mathbf{X}\, \mathbf{C}_i = \underbrace{\,{}^{base}\mathbf{T}_{board}}_{\text{常量}}, \qquad \forall i \]

任取两姿态 \(i, j\) 相消常量：

\[ \underbrace{\mathbf{G}_j^{-1}\mathbf{G}_i}_{\mathbf{A}}\, \mathbf{X} = \mathbf{X}\, \underbrace{\mathbf{C}_j\mathbf{C}_i^{-1}}_{\mathbf{B}} \]

眼在手外。标定板改装到末端上（\(\mathbf{Z} = {}^{end}\mathbf{T}_{board}\) 常量），相机固定。链：

\[ \mathbf{Y}\,\mathbf{C}_i = \mathbf{G}_i\,\mathbf{Z} \qquad \forall i \]

两姿态相消（左右同乘整理后）：

\[ \underbrace{\mathbf{G}_j\mathbf{G}_i^{-1}}_{\mathbf{A}'}\,\mathbf{Y} = \mathbf{Y}\, \underbrace{\mathbf{C}_j\mathbf{C}_i^{-1}}_{\mathbf{B}} \]

两种构型归一为同一个方程 \(\mathbf{A}\mathbf{X} = \mathbf{X}\mathbf{B}\)，只有 \(\mathbf{A}\) 的构造方向相反（手内 \(\mathbf{G}_j^{-1}\mathbf{G}_i\)，手外 \(\mathbf{G}_j\mathbf{G}_i^{-1}\)），\(\mathbf{B}\) 同形。这是手眼标定最优雅的地方：一个求解器通吃两种构型。

5.3 Tsai-Lenz 求解（经典闭式法）

把 \(\mathbf{A}\mathbf{X} = \mathbf{X}\mathbf{B}\) 按旋转/平移分开解：

旋转部分：\(\mathbf{R}_A\mathbf{R}_X = \mathbf{R}_X\mathbf{R}_B\)。取 \(\mathbf{A}, \mathbf{B}\) 旋转的修正罗德里格斯表示 \(\boldsymbol{P}_g = 2\sin(\theta_A/2)\,\boldsymbol{n}_A\)、\(\boldsymbol{P}_c = 2\sin(\theta_B/2)\,\boldsymbol{n}_B\)，得线性方程：

\[ [\boldsymbol{P}_g + \boldsymbol{P}_c]_{\times}\, \boldsymbol{P}_x = \boldsymbol{P}_c - \boldsymbol{P}_g \]

每对运动给 3 行，多对堆叠后最小二乘解出 \(\boldsymbol{P}_x\)，再还原 \(\mathbf{R}_X\)（\(\theta_x = 2\arctan\|\boldsymbol{P}_x\|\)）。

平移部分：展开齐次方程的平移分量得线性方程：

\[ (\mathbf{R}_A - \mathbf{I})\,\boldsymbol{t}_X = \mathbf{R}_X\boldsymbol{t}_B - \boldsymbol{t}_A \]

同样堆叠求解。两步都是线性最小二乘——这就是 Tsai-Lenz（1989）快而稳的原因。后续发展：Park-Martin（李代数）、Daniilidis（对偶四元数，旋转平移联合）、Andreff（线性化非线性方程），OpenCV 的 calibrateHandEye 五种方法全都有。

5.4 采集规范（决定成败的不是求解器）

  • ≥ 10 组姿态，且旋转轴多样（至少两个不平行方向、避免所有姿态绕同一轴转——旋转约束需要非共面）
  • 禁纯平移：纯平移只约束平移，旋转部分零信息
  • 每组姿态下棋盘完整可见、离焦清晰（PnP 输入的质量上限就是手眼精度的上限）
  • 机械臂的绝对精度要够（D-H 参数误差直接进 \(\mathbf{G}_i\)）；零点/负载参数已标定
  • 温度：相机跑热后内参微变，冷机标定→热机使用会有亚毫米级漂移

5.5 两种构型对比

眼在手内 眼在手外
精度 高（工作距离近，像素当量小） 中（距离远，像素当量大）
视野 随臂动，看哪指哪，无死角设计 固定区域，臂可能遮挡相机
通用性 换工位无需重标（相对相机） 场景固定，一次标定全场用
线缆/惯量 末端增重、线缆随动（疲劳点） 干净
典型应用 视觉伺服抓取、移动抓取 固定工位上下料、分拣

7. 工程化验证清单

标定完成后，闭环验证比误差数字更有说服力：

  1. 重投影自检：用 \(\mathbf{X}\) 把棋盘角点从相机系换算到基座系，移动机械臂后坐标应重合（< 2mm）
  2. 点到点验证：相机看一个固定点，算出基座系坐标，命令末端去触它——Z 方向留 5mm 余量，看横向偏差
  3. 多姿态复验：在工作空间四个象限各做一次验证，误差应均匀（某个象限系统性偏 = 臂的 D-H 误差，不是相机的锅）
  4. 温度与时间：连续运行 2h 后复验，亚毫米漂移正常，毫米级要查相机支架松动
  5. 把 \(\mathbf{K}\)、dist、\(\mathbf{X}\) 与采样日志一起归档（参数指纹），重标时对比（工程管理习惯见Python 规范）

8. 总结

环节 核心公式/结论 工具
成像 \(s\tilde{\boldsymbol{p}} = \mathbf{K}[\boldsymbol{R}|\boldsymbol{t}]\tilde{\boldsymbol{P}}\) + 径向/切向畸变 —
内参标定 张正友法，重投影误差 < 0.5 px cv2.calibrateCamera
手眼（手内） \(\mathbf{G}_j^{-1}\mathbf{G}_i\,\mathbf{X} = \mathbf{X}\,\mathbf{C}_j\mathbf{C}_i^{-1}\)，求 end→cam cv2.calibrateHandEye
手眼（手外） \(\mathbf{G}_j\mathbf{G}_i^{-1}\,\mathbf{Y} = \mathbf{Y}\,\mathbf{C}_j\mathbf{C}_i^{-1}\)，求 base→cam 同一求解器，A 反向
Tsai-Lenz 旋转：\([\boldsymbol{P}_g+\boldsymbol{P}_c]_\times\boldsymbol{P}_x = \boldsymbol{P}_c-\boldsymbol{P}_g\)；平移：\((\mathbf{R}_A-\mathbf{I})\boldsymbol{t}_X = \mathbf{R}_X\boldsymbol{t}_B-\boldsymbol{t}_A\) 本文 60 行 numpy 实现

一句话心法：内参定相机、外参定安装、手眼定天地。三种标定各管一段，任何一段失准都会伪装成”视觉算法不好”——先看标定，再看算法。
