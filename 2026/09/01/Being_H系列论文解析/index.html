Being_H系列论文解析

VLA Being-H 世界模型 人类视频学习 跨本体泛化 触觉
论文精度与分析 Ego混合数据学习
发布日期:   2026-09-01

BeingBeyond（智在无界）的 Being-H 系列是”从人类视频学机器人”这条路线最完整的工程叙事：H0 证明可行性 → H0.5 解决跨本体 → H0.7 引入对未来的推理 → H0.8 加入触觉。四步棋每一步都精准踩在上一步的瓶颈上，而且全部围绕同一个母题——以自我中心（egocentric）人类数据为混合训练底座（正合本专栏主题）。本文先铺引言与研究背景，再逐篇拆解：核心逻辑、核心公式、核心数据、实验结果，最后解析四代工作的递进关系并给出核心参考文献。

1. 引言：VLA 的数据战争与”人类视频”路线

问题的原点：VLA 模型的能力上限由数据决定，而机器人操作数据是所有 AI 数据里最贵的。三条主流取数路线各有死穴：

数据路线 代表 优势 死穴
仿真合成 MimicGen、DreamGen、Isaac Lab 无限量、零采集成本 sim-to-real 鸿沟（接触动力学/视觉纹理差异）
遥操作真机 OXE、DROID、AgiBot World 真分布、真物理 每小时数百元成本，规模与多样性天花板（H0.5 文中对比：AgiBot World 仅约 200 小时桌面数据）
人类视频 Ego4D、EPIC-Kitchens、网络视频 海量（数千小时级公开 + 互联网无限）、天然灵巧多样 无机器人动作标签、视角混杂、无触觉

Being-H 系列的全部工作可以概括为一句话：把第三条路线的死穴逐个拆掉——H0 解决”人类视频没有机器人动作”（手部运动建模 + 物理对齐），H0.5 解决”只有人手没有机器本体”（统一动作空间），H0.7 解决”只会模仿不懂因果”（潜空间未来推理），H0.8 解决”视频里没有触觉”（TactoHand 触觉反推）。

核心信念（H0 论文原话的精神）：人手是”基础操作器”（foundation manipulator）——互联网级的人类操作视频就是机器人领域的”网页文本”，灵巧性的先验藏在这里，而不是在昂贵的遥操作台里。

生态位：与 π 家族（押注机器人经验数据 + 强化学习）、GR00T（押注合成数据管线）构成当前具身大模型的三大数据哲学；Being-H 是”人类中心主义”路线的旗手，也是国内体系化程度最高的系列之一。

2. 相关研究背景

以下每项研究都用【标签】标明主要对应四代技术中的哪一代（H0=人类视频预训练与运动分词，H0.5=跨本体统一，H0.7=潜空间世界模型，H0.8=触觉），随后给出系列所依赖的具体技术栈解析，最后总结同异。链接集中列在第8节。

2.1 VLA 主线：Being-H 站立的肩膀【全系基线】

RT-1【H0】。动作 token 化的开创者：11 维动作各离散成 256 bins，13 万真机回合训练 35M Transformer。它是 H0”动作 token”的直接先例，但其数据全靠遥操作——H0 要解的正是这个数据瓶颈。

RT-2【H0】。VLM 骨干 + 动作 token 共同训练，知识迁移涌现。H0 的”物理指令调优”把它的思想从”网络语言知识”平移到”网络运动知识”。

OpenVLA / OpenVLA-OFT【H0.5】。全开源 7B 底座与并行连续解码强化版——H0.5/H0.7 实验表里的主要开源对照基线。

π0 / π0.5【H0.5、H0.7】。VLM 骨干 + 流匹配动作专家——与 H0.5/H0.7 的动作头完全同构，是贯穿两篇实验的直接比较对象；差异在预训练数据（机器人真机 vs 人类视频）。

GR00T N1【H0.5】。人形全栈 + DreamGen 合成数据——跨本体与人形场景的对照，”造数据”路线代表。

Gemini Robotics【全系】。前沿模型直连机器人，闭源能力上限参照。

RDT-1B【H0.5】。双臂扩散基座——H0.5 双臂能力的对照。

2.2 人类视频学习：Being-H 的直接同行【H0/H0.8 主场】

R3M / VIP / CURL【H0】。对比学习时代从人类视频学视觉表征——只学”看”不学”动”，H0 把这一步推进到直接学动作。

Ego4D / Ego-Exo4D / EPIC-Kitchens / HOI4D【H0、H0.8】。第一人称数据基座——UniHand 1.0/3.0 的原料库。

EgoDex【H0】。思路最接近的竞品：同样”第一人称视频 + 手部运动 + 指令”学灵巧操作；差异在 H0 更强调物理空间对齐与 RVQ token 的毫米级腕部精度。

EgoVLA【H0】。直接从第一人称人类视频预训练 VLA；差别主要在数据管线规模与后训练设计。

MAPLE【H0】。从第一人称视频提炼灵巧操作先验注入策略——先验编码器路线，规模小于 H0 的端到端预训练。

GLOVER++【H0】。从人类行为学可供性（物体怎么用、哪里能抓）——空间级先验，与 H0 的动作级学习互补。

DexUMI【H0、H0.8】。手戴传感装置（相机+IMU）采集带真值尺度的演示——用穿戴硬件解纯视频的尺度/遮挡问题；H0 用三源算法管线（mocap+VR+RGB）解同一问题。

Dex1B【H0】。十亿级生成扩增演示——“数量”路线，与 H0 的”真实多样性”路线对照。

Gen2Act【H0、H0.7】。人类视频生成模型合成 novel 场景演示再模仿——生成式数据 + 隐式世界模型双重身份。

VidBot【H0】。野外 2D 视频学 3D 动作零样本迁移——单任务级验证。

EgoMimic【H0】。Aria 眼镜第一人称数据做模仿学习规模化——硬件采集路线代表。

UMI / UMI-on-Legs【H0.5】。手持夹爪全民教学与移动操作扩展——“统一接口”思想与 H0.5 统一动作空间同源。

触觉侧背景【H0.8】。此前的触觉学习集中在传感器级表征（自监督触觉编码一类工作）或单点触觉策略，H0.8 首次把触觉搬进第一人称视频的大规模预训练（TactoHand）——直接可引的同行很少，蓝海本身是贡献。

2.3 动作分词与潜动作【H0 分词；H0.5 动作空间】

FAST【H0】。DCT+BPE 通用动作分词——与 H0 的 RVQ 手部分词同族异构（频域 vs 码本域）。

LAPA【H0】。先从无标签视频学潜动作、再初始化 VLA——“视频→动作”的另一座桥。

UniVLA【H0.7 相邻】。任务中心潜动作 + 潜空间自回归——潜空间推理的近亲。

VILLA-X / DexVLA【H0、H0.5】。潜动作建模增强与即插扩散专家——token 化/连续头混合路线的代表。

2.4 视频预训练与世界模型【H0.7 对照系】

GR-1【H0.7】。视频生成式预训练迁移操作——“看视频学动力学”早期代表。

Action-free Reasoning【H0.7】。动作前插入无动作推理阶段——与 H0.7 潜查询同思（推理与执行分离），但它分离显式思考、H0.7 分离隐式预知。

2.5 技术栈解析：四代工作依赖的具体工具

把四篇论文拆到工具层，得到一张”系列技术栈地图”：

读表要点：四代的差异几乎全部落在”分词层（H0）→ 架构层（H0.5）→ 推理层（H0.7）→ 数据层（H0.8）”，而骨干、动作头、评测栈高度复用——这正是”系列”而非”四个独立模型”的原因。

2.6 相同点与不同点总结

相同点（人类视频学习一族的公共信念）：

  1. 数据主张一致：人类视频是机器人操作数据的最大矿藏，都瞄准”无机器人标签”的视频源
  2. 都要跨过”视频→动作”的鸿沟：或显式（手部姿态估计）、或隐式（潜动作/可供性）、或硬件（UMI/DexUMI 采集装置）
  3. 下游都汇入同一动作生成范式：AR token 或流匹配/扩散连续头

不同点（四个关键分叉维度）：

维度 代表做法 Being-H 的选择
鸿沟怎么跨 手部姿态（EgoDex/EgoVLA）/ 潜动作（LAPA/UniVLA）/ 可供性（GLOVER++）/ 穿戴硬件（UMI/DexUMI） 三源融合管线（mocap+VR+RGB）+ RVQ 毫米级手部 token
目标规模 单任务/单本体验证（VidBot、EgoMimic）或中等模型 基础模型化：8B、跨 30 本体、50 万小时
空间理解 2D 像素或隐式 3D 显式物理空间对齐（弱透视投影 + 视角平衡）
未来感知 无（纯模仿）或视频 rollout（GR-1/Gen2Act 一系） 潜空间双分支：要预知不要 rollout（H0.7）

定位一句话：同类工作各自验证了”人类视频可用”的某一面，Being-H 系列的特殊性在于把整条链（数据管线 → token 化 → 跨本体架构 → 世界推理 → 触觉）做成了自洽的体系，并以三个量级的数据增长持续加码。

3. Being-H0：把人类手部视频变成 VLA 预训练语料

核心逻辑。现有 VLA 的数据困境（见引言）：仿真有鸿沟、遥操作缺规模——而人手本身就是最高产的灵巧操作者，网络上有海量人类操作视频。H0 的答案是**物理指令调优（Physical Instruction Tuning）**三段式：

  1. 大规模预训练：以人类视频（视频 \(\boldsymbol{v}\)、文本 \(\boldsymbol{t}\)、手部运动 \(\boldsymbol{m}\) 三元组 \(\mathcal{D}=\{(\boldsymbol{v}_i,\boldsymbol{t}_i,\boldsymbol{m}_i)\}\)）训练自回归 VLA，训练目标就是标准下一 token 预测：
\[ \mathcal{L}=-\sum_{j=1}^{L}\log P_{\Theta}\big(y_j \mid \mathcal{X}_Q,\ \hat{y}_{1:j-1}\big) \]
  1. 物理空间对齐：弱透视投影对齐把 2D 视频里的手对到 3D 物理空间（3D 推理能力），配合视角不变的运动分布再平衡——解决”网络视频视角五花八门”的问题
  2. 后训练适配：向灵巧操作机器人迁移

核心公式：部件级运动 token 化。手部运动 \(\boldsymbol{m}=\{\theta, \boldsymbol{r}_{rot}, \tau, \beta\}\)（关节角、全局旋转、平移、手型），经**残差量化（RVQ）**离散成 token——正是本站运动离散化技术第3节的技术：

\[ r_0=z_i^{(g)},\quad q_l=\arg\min_{c\in\mathcal{C}^{(g)}}\|r_{l-1}-c\|_2,\quad r_l=r_{l-1}-q_l,\qquad \hat{z}_i^{(g)}=\sum_{l=1}^{L}q_l \]

token 化器训练损失在标准”重建 + 承诺”之外加了腕部加权重建——腕部位姿决定全局轨迹，必须毫米级准：

\[ \mathcal{L}=\mathcal{L}_{\text{recon}}+\lambda_1\mathcal{L}_{\text{commit}}+\lambda_2\underbrace{\|\boldsymbol{w}-\hat{\boldsymbol{w}}\|_2^2}_{\boldsymbol{w}=[\boldsymbol{r}_{rot},\ \tau]\ \text{腕部加权}} \]

（实测毫米级重建精度。）

核心数据：UniHand。数据管线整合三类异构源——动捕（MotionX/EgoBody/Nymeria）、VR、纯 RGB 视频（手部姿态标准化 + 任务描述标注 + 指令生成）——全量标注产出超过 1.65 亿对”运动-指令”，其中含 44 万+ 任务轨迹、1.3 亿+ 帧、1100+ 小时视频；预训练取数百万规模的均衡子集。

实验结果。(1) 手部运动生成与翻译：在 MPJPE / MWTE / PA-MPJPE / M2T R@3 / FID 指标上全面领先（语义一致性类指标 M2T R@3 与 FID 优势显著）；(2) 规模律成立：模型与数据放大，性能稳定提升（有 8B 变体）；(3) 真机灵巧操作：物理指令调优后成功率为各任务最高（每任务 20 次随机初始位测试）。

意义：证明了”人类视频 → 灵巧 VLA”这条数据路线的可行性，并给出 token 化与数据管线两件工具——后续三代全部继承。

4. Being-H0.5：人类母语与跨本体统一

核心逻辑。H0 只会”人手”，机器人形态各异（morphological heterogeneity）怎么办？H0.5 的主张：把人类交互轨迹当作物理交互的”母语”——所有本体先在人类语义空间里学”做什么”，再各自学”怎么做”。三个支柱：

  1. 统一动作空间（Unified Action Space）：每个本体 \(e\) 的状态/动作经映射 \(\Phi_e\) 进入语义对齐的统一槽位：
\[ \boldsymbol{s}=\Phi_e(\boldsymbol{s}^{(e)}),\qquad \boldsymbol{a}=\Phi_e(\boldsymbol{a}^{(e)}) \]

低资源机器人可以从人类数据与高资源平台”借力”（bootstrap）
2. 统一序列建模 + 多任务预训练：全部模态（vision/text/state/action）拼成 token 序列 \(\mathcal{S}=[\boldsymbol{x}_1,\dots,\boldsymbol{x}_K]\)，\(\boldsymbol{x}_k=\langle m_k, C_k\rangle\)（模态标记 + 内容），联合损失：

\[ \mathcal{L}=\lambda_{\text{text}}\mathcal{L}_{\text{text}}+\lambda_{\text{act}}\mathcal{L}_{\text{act}},\qquad \mathcal{L}_{\text{act}}=\lambda_1\mathcal{L}_{\text{FM}}+\lambda_2\mathcal{L}_{\text{MASK}} \]

动作头是流匹配（\(\boldsymbol{x}_t=(1-t)\boldsymbol{x}_0+t\boldsymbol{a}_i\)，目标速度 \(\boldsymbol{u}_t=\boldsymbol{a}_i-\boldsymbol{x}_0\)——与本站生成范式流匹配一节完全同式）加掩码建模
3. 架构：Mixture-of-Transformers + Mixture-of-Flow（MoF）——共享”运动基元”主干 + 各本体专属专家解耦；落地两件套：流形保持门控（Manifold-Preserving Gating，抗传感器漂移）与通用异步分块（Universal Async Chunking，把动作块控制推广到不同延迟/控制频率的本体）

核心数据：UniHand-2.0——迄今最大的具身预训练配方：3.5 万+ 小时、1200 亿 token、4 亿+ 样本、30 种本体；成分 = 1.6 万小时第一人称人类视频 + 1.4 万小时机器人操作 + 0.5 万小时通用视觉-语言数据。对比：文中指出 AgiBot World 仅约 200 小时桌面操作。

实验结果。仿真 SOTA：LIBERO 98.9%、RoboCasa 53.9%；五个真实平台验证；对未见机器人形态出现零样本迁移的涌现能力。开源力度大：真机部署基建与 1000 GPU 时预训练配方。

意义：把 H0 的”人类视频”升级为”人类 + 机器人 + 通用 VL”的混合配方，并用统一动作空间 + MoF 把”一个模型管所有本体”跑通。

5. Being-H0.7：不生成未来帧的世界模型

核心逻辑。VLA 的隐疾：动作监督稀疏，模型学到的是”观测→动作”的捷径映射，没有表征动力学、接触与任务进度；而视频世界模型（WAM）靠逐帧 rollout 预测未来，代价高昂且大量预测与控制无关的视觉细节。H0.7 的方案——潜空间世界-动作模型：在感知与动作之间插入 \(K\) 个可学习潜查询（latent queries）\(Q\)，序列变成：

\[ S=\big[x;\ o_{-H:0};\ s;\ Q;\ a_{0:T}\big] \]

核心公式：双分支对齐训练。训练时两个分支：

  • 先验分支（部署用）：从当前上下文推断潜状态 \(h^{\text{prior}}\)
  • 后验分支（仅训练）：用未来观测的编码 \(z^{\text{post}}=E(\tilde{o}_{0:T})\) 替换查询，得到”看过未来的”表征 \(h^{\text{post}}\)

两支在潜空间逐层对齐：

\[ \mathcal{L}_{\text{align}}=\frac{1}{L}\sum_{\ell=1}^{L}\frac{1}{|h_\ell|}\big\|h_\ell^{\text{prior}}-h_\ell^{\text{post}}\big\|_F^2 \]

外加两个防退化正则——范数约束（潜向量的下限裁剪，防塌缩到零）与秩约束（对 \(\hat{H}\hat{H}^{\top}\) 特征值谱的熵正则，防潜空间维度坍缩）：

\[ \mathcal{R}_{\text{norm}}(h)=\big[\mathrm{ReLU}(\tau-\|h\|_2)\big]^2,\qquad \mathcal{R}_{\text{rank}}(H)=-\sum_i p_i\log p_i,\quad p_i=\lambda_i\Big/\textstyle\sum_j\lambda_j \]

动作头沿用流匹配（\(a_t=ta+(1-t)\epsilon\)，\(u_t=a-\epsilon\)）。推理时丢弃后验分支——没有任何视觉 rollout，预测的”未来”被蒸进了先验分支的潜表征里。

核心数据与实验。六大仿真基准（LIBERO / LIBERO-plus / RoboCasa-50 / GR1 / CALVIN / RobotWin2，每套件 500 次试验）：对比 π0（3B，LIBERO 94%+ 一档）取得 SOTA 或持平；RoboCasa 达 62%+（较 H0.5 的 53.9% 再上台阶）；LIBERO-plus 抗扰动：零样本即约八成成功率，微调后 84.8%；重度视觉域随机化下成功率仅微降（个位数百分比跌幅）。真机覆盖 PND Adam-U、Unitree G1、Franka FR3 三平台五套能力导向任务。

意义：给”世界模型派 vs 直控派”的争论给出第三答案——要世界模型的好处，不要它的开销：未来信息以蒸馏方式进入潜推理，推理成本与普通 VLA 相当。

6. Being-H0.8：把触觉带进第一人称预训练

核心逻辑（据官方研究页，独立论文暂未见 arXiv）。视觉世界模型能预演场景演化，但接触动力学才是灵巧操作的胜负手——关键决策发生在接触界面（力的大小、滑移的前兆），纯视觉看不见。H0.8 把 H0.7 的潜空间世界-动作建模从”视觉预测”扩展到触觉感知交互，号称首个在如此规模的第一人称人类视频上做触觉预训练的模型。三件设计：

  • UniHand-3.0：50 万+ 小时第一人称视频（公开集合 + 数据伙伴网络），比 H0.5 再放大一个量级
  • TactoHand：从普通 RGB 视频中恢复触觉信息——把观察到的手-物交互转化为稠密的接触与接近度监督（视频里没有的”摸起来的感觉”被反推出来）
  • 共享动作槽：手轨迹与机器人控制在同一套动作槽里学习，没有任何本体专属策略头；抓取值由拇指与最近指尖的距离导出——人类预训练到灵巧操作的迁移更顺

演示方向：连续力调制、可变形物体操作等真机接触密集任务。

意义：补上”手眼之外”的最后一感，并彻底统一了人/机器人的动作表征。

7. 四代递进关系：一条主线，四次攻顶

四篇工作不是平行堆料，是同一个体系的四次瓶颈攻坚：

四条贯穿主线：

  1. 数据三级跳：1.65 亿对（H0）→ 3.5 万小时多模态（H0.5）→ 50 万小时第一人称（H0.8）——每一代都把人类数据池放大一个量级，”数据配方”（人类视频 + 机器人 + VL）逐步融合
  2. 动作表征统一：RVQ 运动 token（H0）→ 统一动作空间 \(\Phi_e\)（H0.5）→ 共享动作槽 + 抓取值（H0.8）——“一个动作语义，所有本体共享”贯彻始终
  3. 生成范式站位：AR 语义骨干 + 流匹配动作头从 H0.5 起成为标配（与 π 系、SmolVLA 同流，见生成范式篇）；H0 的 RVQ 分词则是运动离散化在”手部运动”上的大规模应用
  4. 世界模型化：H0.7 的”后验蒸馏进先验”与 H0.8 的触觉潜建模，方向一致——把”会发生什么”内化成推理时的免费先验，而非推理时的显式 rollout

对照业界：这条路径与 π 家族（π0 定架构 → π0.5 泛化 → π0.6 强化学习）互为镜像——Being-H 押注*人类视频数据，π 家族押注机器人经验数据；两者在”流匹配动作头 + 大规模 VLM 骨干”上殊途同归。

8. 研究结果对比分析

8.1 家族内：三代能力的量化接力

Being-H 各代的评测维度不同（H0 考手部运动生成，H0.5/H0.7 考机器人任务），可比的锚点是仿真基准：

基准 H0.5（2026.01） H0.7（2026.05） 代际解读
LIBERO 98.9%（SOTA，且仅用低分辨率 RGB、无辅助模态） SOTA/持平（对 π0 3B 的 94%+ 一档领先） H0.5 已打满，H0.7 保持
RoboCasa-50 53.9% 62.1% 长程家务任务 +8.2 个百分点——潜空间未来推理的直接收益区
GR1（人形双臂灵巧） — 49%+ 人类视频手部先验向人形灵巧手的迁移验证
LIBERO-plus（扰动鲁棒） — 零样本约八成 → 微调 84.8% 视角/纹理/传感器噪声下仅小幅下降，世界-动作表征的抗扰性证据
六基准平均 — 平均排名最高（每套件 500 次试验） 综合泛化的定位

三条读数：(1) H0 → H0.5 的收益在”跨本体与规模”——同一配方覆盖 30 本体并在标准基准打满；(2) H0.5 → H0.7 的收益在”难任务与鲁棒性”——平均分不易再涨的地方，扰动场景与长程家务（RoboCasa +8.2pp）显著提升，正是”未来感知”要解的问题；(3) H0 的贡献维度不同——手部运动生成的 MPJPE/FID 类指标无法与后两代直接比，但它创造的 RVQ 分词与 UniHand 数据是后两代的地基（消融见各论文）。

8.2 跨家族：Being-H vs π 系（两条数据路线的正面参照）

两个系列互为镜像（详见本站PI 系列解析），可对齐比较的维度：

维度 Being-H 系 π 系
预训练数据 人类视频为主（1.65 亿对 → 3.5 万 h → 50 万 h） 机器人真机为主（~1 万 h 演示 + 1% 开源 → 部署经验）
架构 VLM 骨干 + 流匹配头（H0.5 起） VLM 骨干 + 流匹配专家（π0 起）——同构
灵巧性来源 人类手部先验（RVQ 运动 token） 真机灵巧演示 + RL 经验
跨本体 统一动作空间 + MoF（30 本体） 多平台训练 + π0.7 零样本跨本体
超越演示 （尚未公布 RL 类工作） RECAP：吞吐 2×、失败率减半
标志结果 陌生家庭厨房/卧室整理（H0.5 的路数）+ 六基准 SOTA 咖啡机 13h、开箱即用比肩 RL 专家
LIBERO 上的直接交点 H0.7 对 π0（3B，94%+）取得 SOTA 或持平 π 系未以 LIBERO 为主战场（主打真机）

判读：(1) 在公开仿真基准上 Being-H0.7 留下了对 π0 的直接胜绩（同表比较）；但 π 系的护城河在真机硬指标与经验进化（RECAP 的吞吐/失败率、13 小时级长跑），这类评测 Being-H 暂未公布对等结果——两条路线的证据域几乎不重叠，各自都在自己选定的战场取胜；(2) 架构层已收敛（双塔 + 流匹配），竞争的本质是数据路线之争：人类视频的”多样性 + 灵巧先验” vs 真机经验的”分布内 + 可自我改进”；(3) 最可能的终局是合流——用人类视频打底、用部署经验进化，两家的下一代都在向对方的方向移动（π0.5 已混入异构数据，Being-H 的 UniHand-2.0 已含 1.4 万小时机器人数据）。
