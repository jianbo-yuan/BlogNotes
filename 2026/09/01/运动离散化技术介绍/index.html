运动离散化技术介绍

VLA 运动离散化 向量量化 VQ-VAE 残差量化 FSQ 动作分词
科研工具 数学理论基础
发布日期:   2026-09-01

自回归模型（尤其大语言模型 LLM）只吃离散 token——要让它们处理连续的运动/动作数据，必须先把连续量变成离散标记，这就是运动离散化（量化）。它是生成范式中自回归路线的地基：RT-1/OpenVLA 的动作 token、VQ-BeT 的潜动作、π0-FAST 的紧凑分词，底层全是本文的技术。

离散化要同时优化两个互相拉扯的目标：表示精度（量化误差越小越好）与序列效率（token 数越少、词表越紧凑越好）。技术谱系按这两条轴演进：

本文按谱系逐个展开：理论推导、代表案例（配论文架构图与视频资源）、以及四段实测通过的 numpy 实现（均匀分桶 / VQ 码本 / 残差量化 / FSQ）。

1. 第 0 层基线：均匀分桶（标量量化）

原理：每个动作维度独立地把值域切成 \(B\) 个均匀格子（RT-1 用 256 bins），格心作为重建值。这是最朴素的”有限档位”量化——也正是一切离散化的下界参照。

误差理论：格子宽 \(\Delta = \frac{R}{B}\)（值域 \(R\)），量化误差在格内近似均匀分布，均方误差：

\[ \mathrm{MSE} = \frac{\Delta^2}{12} \;\Longrightarrow\; \mathrm{RMSE} \propto \frac{1}{B} \]

精度随 bins 线性提升，但词表与序列长度线性变差（\(d\) 维动作 = 每步 \(d\) 个 token）；且各维独立分桶把”联合分布的多模态结构”完全交给下游 AR 自己学。

2. 向量量化：VQ-VAE

原理：维护一个码本 \(\{e_1, \dots, e_K\}\)（\(K\) 个与编码器输出同维的向量）。编码器把连续运动块（或其潜表示）\(z\) 映射到最近邻码字：

\[ z_q = e_k, \quad k = \arg\min_j \|z - e_j\|_2 \]

离散 token 就是码字编号 \(k\)。与逐维分桶的本质区别：码字是学出来的、贴合数据分布的”动作原型”（一个 token 表达整段/整块动作），词表利用率高得多。

训练的三个部件（VQ-VAE 的经典设计）：

  • 直通估计器（STE）：\(\arg\min\) 不可导，前向用量化值 \(z_q\)、反向把梯度原样放行给编码器 \(\frac{\partial L}{\partial z}\Big|_{z_q}\)——“量化当恒等”的近似
  • 码本损失：\(\|{\rm sg}[z] - e_k\|^2\)（sg = stop-gradient）把被选中的码字拉近编码器输出
  • 承诺损失：\(\beta\|z - {\rm sg}[e_k]\|^2\) 反向约束编码器”说话算数”（贴近码字）

码本坍塌（Codebook Collapse）的机理与对策：梯度只流向被选中的码字——用得多的码字越学越好、用不着的永远得不到更新（马太效应），最终 \(K\) 个码字只剩几个在干活。三件对策：EMA 更新（码字按簇均值指数滑动，等价于本文 demo 里 k-means 的质心重置——天然消灭死码字）、死码字重置（长期未用的码字搬到当前编码器输出密集区）、降 K 或改用余弦距离。

（图源：VQ-BeT 论文 arXiv:2403.03181，项目页（含演示视频））

案例：VQ-BeT（2024）。机器人动作离散化的代表作：编码器压潜表示 → VQ 码本离散化（如 2048 个动作原型）→ GPT 式 Transformer 自回归预测 token 序列 → 解码回连续动作。它同时用到了”分层”思想（见第4节），在 PushT/RLBench/现实机器人上验证了”VQ token + AR”对多模态动作的有效性。

3. 残差量化（RQ）：多层码本堆精度

原理：单层码本精度不够时，不加大 \(K\)，而是级联多层小码本。第一层量化后计算残差，第二层量化残差，以此类推：

\[ x \approx e^{(1)}_{k_1} + e^{(2)}_{k_2} + \cdots + e^{(L)}_{k_L}, \qquad r^{(\ell)} = r^{(\ell-1)} - e^{(\ell)}_{k_\ell} \]

核心账本：\(L\) 层、每层 \(K\) 个码字，有效词表 = \(K^L\) 指数增长，而每层码本只有 \(K\) 个向量（训练稳、显存省）。8×8 两级 = 64 种组合，效果接近 64 个独立码字，且每层小码本都能”满载”。

案例：RQ-Transformer（离散序列建模的经典配套：RQ-VAE 造 token，Transformer 建模 token 流）；π0-FAST 论文中与残差量化的对比（FAST 用频域压缩达到相近压缩率）；音频/视频 tokenizer（SoundStream/EnCodec 系列）普遍用 RVQ 堆精度——运动数据正沿同一路径迁移。

4. 分层量化（Hierarchical VQ）：粗到细

原理：把运动在时间或语义上分层——底层 token 表达局部细节（关节角度增量），高层 token 表达全局结构（身体位移、动作语义）。生成时自回归先出高层（粗），再细化底层（细），天然对应”先决定做什么、再决定怎么做”。

案例：VQ-BeT 的 coarse-to-fine 正是它的实例——粗码字选”动作原型”（走到哪个抓取流派），局部偏移 token 修”毫米级细节”；分层大小脑（智元 GO-1 一系）在架构层做同样的事；视频侧的 Genie 潜动作模型（从画面变化反推离散”潜在动作”）则是无监督版的语义层离散化。

5. 无查找量化（Lookup-free）：FSQ 与 LFQ

原理：彻底抛弃码本表。**FSQ（Finite Scalar Quantization）**对每个标量维度直接映射到 \(L\) 个固定档位：

\[ \hat{z}_i = \mathrm{round}\Big(\frac{L_i-1}{2}\big(\tanh(z_i)+1\big)\Big) \cdot \frac{2}{L_i-1} - 1 \]

\(d\) 维、每维 \(L\) 档 → 隐式词表大小 = \(L^d\)（不需要任何 Embedding 矩阵存储码字，档位组合即码字）。**LFQ（Lookup-Free Quantization）**是其极端版：每维二值/多值，直接二进制编码。

为什么天生无坍塌：码字不是可训练参数，而是档位组合隐式定义的——不存在”某个码字学不到梯度”的问题；量化点均匀覆盖值域（对比 VQ 码字可能挤在数据密集区）；训练极其稳定、显存大降。

（图源：MAGVIT-v2 论文 arXiv:2310.05737）

案例：MAGVIT-v2。LFQ 的成名作：把视频 token 化器的词表做到 \(2^{18}\) 而无坍塌，在 ImageNet/视频生成基准上大幅刷新 tokenizer 性能，直接带火了 lookup-free 路线；此后具身领域的动作 token 化开始跟进 FSQ（”VQ-VAE Made Simple”）。

6. 方法对比

方法 词表 精度来源 坍塌风险 序列效率 代表
均匀分桶 \(B\)（每维） bins 数量 无 差（每维每步一 token） RT-1 / OpenVLA
VQ-VAE \(K\) 码字贴合分布 高（需 EMA/重置） 好（一 token 一原型） VQ-BeT
残差 RQ \(K^L\) 指数 层层削残差 中（每层小，可控） 好 RQ-VAE/EnCodec 系
分层 H-VQ 各层独立 粗到细分治 中 最好（高层短序列） VQ-BeT 两级
FSQ/LFQ \(L^d\) 隐式 档位密度 零 好 MAGVIT-v2
