VLA 流匹配 强化学习 模仿学习 π0 Physical Intelligence
论文精度与分析 模仿学习

Physical Intelligence（PI）的 π 系列是具身大模型”工程与科学双满分”的代表作：π0 定下”VLM 骨干 + 流匹配动作专家”的架构范式，FAST 换自回归头做最干净的范式对照，π0.5 攻开放世界泛化，π*0.6 用 RECAP 把强化学习带进 VLA，π0.7 用上下文条件化实现”开箱即用、性能比肩 RL 专家”。五代工作构成一条完整的技术演进链：架构 → 分词 → 泛化 → 经验 → 可控。

1. 引言：从模仿学习到机器人基础模型

范式背景。机器人学习长期困在”每个任务一套专用系统”：行为克隆（模仿学习）在单任务上可行，但数据贵、泛化差；与此同时 NLP/视觉被”预训练基础模型”彻底改写。2022-2024 年，两条路合流出 VLA（视觉-语言-动作）模型：RT-1/RT-2 证明动作可以 token 化进语言模型，Diffusion Policy/ACT 证明连续动作块扩散/隐变量生成能处理高频灵巧任务——但两派各有死穴：AR 路线丢精度限频率（2~10Hz），扩散路线与 VLM 语义割裂（去噪器不知道”指令”）。π 系列从这一断层出发。

π 系列的五问递进。每一代都在回答前一代留下的核心问题：

  1. 架构怎么搭（π0）：怎么让 VLM 的互联网知识无损流向连续高频动作？——不要把动作塞进语言 token，用独立的流匹配动作专家挂接骨干
  2. 分词要不要（FAST）：自回归路线还能不能救？——能，但必须换掉”逐维逐帧分桶”的朴素分词
  3. 怎么出实验室（π0.5）：只在训练环境好使的模型没有意义——异构数据协同训练 + 语义子任务预测
  4. 怎么超越演示（π*0.6）：模仿学习的天花板是演示质量——RECAP，把 RL 的自我改进装进 VLA 全流程
  5. 怎么被操控（π0.7）：通才模型输出”不可预测”——上下文条件化，用”怎么做”的多模态提示操控策略

与 Being-H 的镜像（详见本站解析）：π 系全部押注机器人真机数据（1 万小时演示 → 自主经验 → 部署数据），Being-H 押注人类视频；两家在”VLM 骨干 + 流匹配头”上殊途同归，在数据哲学上背道而驰——这是当前具身大模型最有信息量的一组对照实验。

2. 相关研究背景

每项研究标注【对应代际】，随后给出技术栈解析，最后总结同异。

2.1 模仿学习与动作块生成【π0 血统】

ACT【π0、FAST】。CVAE 隐变量 + 50Hz 动作块（ALOHA 硬件）——“高频灵巧任务需要整块动作“的最早证明。π0 的 H=50 动作块直接延续此设定；其”隐变量决定动作风格”的思想与流匹配的随机起点一脉相承。

Diffusion Policy【π0】。动作扩散三板斧（整块生成/滚动时域/轻量去噪器）——π0 最直接的前身。π0 的三点升级：去噪器从孤立小网络升级为与 VLM 全注意力交互的专家；扩散采样换流匹配（路径更直、步数更少）；数据从单任务演示升级为跨平台万小时级。

Diffusion Forcing / 扩散 Transformer 一系【π0 对照】。把扩散与序列建模结合的同期探索——π0 实验中作为消融对照，验证流匹配目标的选择。

2.2 AR 路线与分词【FAST 主场】

RT-2 / OpenVLA(-OFT)【FAST】。AR 路线代表。FAST 论文的出发点正是它们的标准分桶在高频灵巧数据上”完全失败”——问题不在自回归，在分词。

LLM 分词血统（BPE）【FAST】。语言模型早已证明”分词决定序列模型上限”（BPE 合并高频子串）；FAST 把同一思想搬进动作域——先压缩（DCT）再 BPE，与”先学字母表再造句”同构。本站运动离散化系统梳理了这一技术族。

VQ-BeT / 码本系【FAST 相邻】。向量量化”动作原型”——码本域 vs FAST 的频域，同族异构。

2.3 通用策略与数据联盟【π0、π0.5】

Octo【π0】。开源通用策略 + 扩散头——“机器人基座”理念先声；π0 实验中的基线之一（320k 步对照）。

Open X-Embodiment / OXE + Bridge v2 + DROID【π0、π0.5】。跨机构数据联盟——π0 预训练混入（约占 1%，其余为专有万小时数据）；π0.5 的异构协同训练是同一精神的深化：多机器人 + 网络数据 + 语义标注。

GR00T N1 / DreamGen【π0.5】。合成数据路线同行对照。

2.4 强化学习进 Transformer 策略【π*0.6 血统】

离线 RL 经典（IQL/AWR/优势加权系）【π*0.6】。离线数据上学策略改进的两大流派——RECAP 的”优势条件化”是优势加权思想在 VLA 时代的化身：不直接改策略梯度，而是把优势值变成条件，训练仍是最稳定的似然最大化。

Human-gated DAgger【π*0.6】。专家在自主执行中介入纠正的在线数据采集范式——RECAP 把”干预数据”与演示、自主数据统一进价值函数训练。

Q-Transformer【π*0.6】。AR + Q 学习的早期尝试——同问”RL 怎么进 Transformer”，但 RECAP 保留流匹配连续头、用条件化而非 Q 值 argmax，对高频动作更友好。

2.5 可控性与上下文学习【π0.7 血统】

LLM 指令跟随 / 上下文学习【π0.7】。π0.7 的本质是把 LLM 的”指令 + 风格控制”平移到机器人：条件 \(\mathcal{C}_t\) 不只说”做什么”，还说”怎么做“（子目标图像、历史成绩元数据、策略描述）——具身版的 instruction following + in-context learning。

Classifier-Free Guidance 式条件 dropout【π0.7】。训练时对各类条件随机丢弃（详见第7节数字），推理时可通过条件组合”操控”策略——与文生图 CFG 同一思想的不同用法。

RTC 实时分块【π0.7】。推理延迟下保持动作平滑的分块执行机制——工程上让 5 步去噪的通才模型能在 240ms 延迟下稳定 50Hz 控制。

3. π0：VLM + 流匹配动作专家（架构奠基）

核心逻辑。三个障碍——数据、泛化、鲁棒——的统一答案是通用机器人策略（机器人基础模型）。架构主张：动作不该被塞进语言的离散 token，而应由独立的连续动作专家生成，专家通过注意力接收 VLM 的语义表征——“大脑管语义、小脑管动作”。

理论分析：为什么是流匹配（而非离散 token 或扩散）。三个理由层层递进：

  1. 连续多模态分布：灵巧动作的分布是多模态的（同一指令多种手法），离散 token 的交叉熵只能分桶近似，扩散/流匹配天然采样多模态
  2. 训练稳定性与高频适配：流匹配回归的是常数速度场 \(u = A - \varepsilon\)（比扩散的噪声预测目标更平缓），且整个 H=50 动作块并行去噪——没有 AR 的逐 token 串行瓶颈，50Hz 控制可行
  3. 推理时计算可调：步数是超参（\(\delta\) 越小越准越慢）——同一模型可在”快糙”与”慢精”之间切换，AR 与固定步扩散都做不到这么干净

核心公式。观测 \(\boldsymbol{o}_t=[\boldsymbol{I}^1_t,\dots,\boldsymbol{I}^n_t,\ell_t,\boldsymbol{q}_t]\)（多相机、语言、本体状态），动作块 \(\boldsymbol{A}_t\)（\(H=50\)）：

\[ q(\boldsymbol{A}_t^{\tau}\mid\boldsymbol{A}_t)=\mathcal{N}\big(\tau\boldsymbol{A}_t,\ (1-\tau)\mathbf{I}\big):\quad \boldsymbol{A}_t^{\tau}=\tau\boldsymbol{A}_t+(1-\tau)\boldsymbol{\varepsilon},\qquad \boldsymbol{u}=\boldsymbol{A}_t-\boldsymbol{\varepsilon} \]

推理 Euler 积分（10 步）：\(\boldsymbol{A}_t^{\tau+\delta}=\boldsymbol{A}_t^{\tau}+\delta\,\boldsymbol{v}_\theta(\boldsymbol{A}_t^{\tau},\boldsymbol{o}_t)\)，\(\delta=0.1\)。

核心数据。~1 万小时专有真机演示（当时最大）+ 1% 开源（OXE/Bridge v2/DROID）；单任务 5~100+ 小时；覆盖单臂、双臂、移动操作。

实验结果。(1) 预训练零样本评测：在全部任务上取得 >50% 最大得分，全面超越基线——关键消融：“对齐算力”版 π0（160k 步，与 OpenVLA 完全同训练步数）仍全面胜过 OpenVLA（160k）与 Octo（320k），说明优势来自架构而非算力堆叠；π0-small（去掉 VLM 预训练的小模型）也胜过 OpenVLA/Octo，而 π0 对 π0-small 的提升证明 VLM 预训练本身贡献显著。(2) 微调评测 20+ 任务：超越先前 VLA 与灵巧专用模型（含 ACT 一系）；Tupperware 等最难任务上 1 小时数据微调即显著领先。(3) 50Hz 叠衣等灵巧任务实时控制。意义：确立 π 形态架构 + “VLM 预训练有用”的严格证据链。

4. FAST / π0-FAST：动作分词的救赎（AR 对照版）

核心逻辑与理论。AR VLA 的瓶颈在分词：逐维逐帧分桶把 \(H\times|\mathcal{A}|\) 维的动作块切成海量弱相关 token——高频灵巧数据的相邻帧高度冗余，朴素分桶让自回归学到的是”噪声级”转移。FAST 形式化：把动作块 \(\boldsymbol{a}_{1:H}\)（维数 \(|\mathcal{A}|\)）映射为词表 \(|\mathcal{V}|\) 上的 \(n\) 个 token——关键在映射函数。FAST 三步：DCT（时域→频域，能量集中低频，序列有效长度骤降）→ 幅度量化 → BPE（在动作语料上合并高频模式）。哲学与 LLM 完全同构：好分词 = 压缩。

实验结果。(1) 朴素分桶在标准高频灵巧基准上完全失败（论文核心图之一）；(2) FAST 使 AR VLA 在灵巧与长程任务上匹配 π0 流匹配版的性能，同时训练快 5×；(3) FAST+：100 万真机轨迹预训的通用分词器，可作黑盒接入任意 VLA。意义：证明”AR vs 生成式”之争很大程度是”分词”之争；FAST+ 成为后续模型（含 π*0.6 文本通道）的标准件。

5. π0.5：异构协同训练与开放世界泛化

核心逻辑与理论。实验室到荒野的差距靠知识迁移填，π0.5 的配方有三味药：

  1. 异构协同训练（co-training）：多机器人数据 + 网络数据 + ~400 小时移动操作机器人在真实家庭采集的数据混合
  2. 语义-动作联合预测：对多子任务数据人工标注语义子任务，模型先（FAST 文本通道）预测子任务标签、再以子任务为条件生成低层动作——“想清楚再动手”的显式化
  3. 归一化与配比工程：各数据集按每维 1%/99% 分位归一到 \([-1,1]\)；混合比例消融确定

实验结果。(1) 消融证明知识迁移（跨机器人/网络数据/子任务预测）是泛化的必要条件；(2) 评测设计严谨：先在可复现的模拟环境验证，再进三个从未见过的真实家庭（3 厨房 + 3 卧室）、双机型终测，采用部分给分制（如”放一半碗进水槽 ≈ 50% 分”）量化长程家务完成度；(3) 首次端到端学习系统完成厨房与卧室清理整理。意义：从”任务”走向”环境”；其骨干成为 π*0.6 的直接底座。

6. π*0.6 / RECAP：从经验中学习（RL 进 VLA）

核心逻辑与理论。模仿学习的天花板是演示质量；RECAP（RL with Experience and Corrections via Advantage-conditioned Policies）的三步循环：

  1. 自主采集：策略自主 rollout，专家可随时遥操作介入纠正（human-gated DAgger）
  2. 价值函数训练：在”演示 + 自主数据 + 干预”三类异构数据上训练分布价值函数
  3. 优势条件化策略提取：由优势构造改进分布并做 KL 提取（策略改进有保证）：
\[ \hat{\pi}(\boldsymbol{a}\mid\boldsymbol{o})\ \propto\ \pi_{\text{ref}}(\boldsymbol{a}\mid\boldsymbol{o})\,\exp\big(A^{\pi_{\text{ref}}}(\boldsymbol{o},\boldsymbol{a})/\beta\big)\ \Longrightarrow\ \mathcal{J}(\hat{\pi})\geq\mathcal{J}(\pi_{\text{ref}}),\qquad \min_\theta\ \mathbb{E}\big[\mathrm{KL}(\hat{\pi},\pi_\theta)\big] \]

为什么条件化而不是策略梯度：策略梯度对异构离线数据脆弱、易熵塌缩；条件化把 RL 变回似然最大化（给策略看”好坏标签” \(I_t\) 二值优势指示），训练与 SFT 一样稳——这是 RECAP 能在数万小时预训练规模上跑通的关键。奖励设计是稀疏 + 时间惩罚：

\[ r_t=\begin{cases}0 & t=T,\ \text{成功}\\ -C_{\text{fail}} & t=T,\ \text{失败}\\ -1 & \text{否则（拖越久罚越多）}\end{cases} \]

离线 RL 预训练：把上述目标跑在**整个预训练数据集（数万小时、多任务多机器人）**上得到通才 π*0.6——离线 RL 首次在 VLA 规模落地。

架构变化：骨干换 Gemma 3 4B；动作专家扩到 860M；子任务文本经 FAST token 输出、stop-gradient 与流匹配专家隔离。

实验结果。真机硬任务三连：咖啡机连续 13 小时无人干预出饮品、新家庭连续 2 小时+叠陌生衣物、工厂真实包装装盒；量化：最难任务上吞吐 ~2×、失败率降 2×以上；价值函数可视化验证其学会了区分成功/失败轨迹。意义：”机器人从自己的部署经验中变强”首次大规模兑现。

7. π0.7：可操控的通才（开箱即用比肩 RL 专家）

核心逻辑与理论。π*0.6 的 RL 专家”每任务练一遍”太贵；π0.7 的答案：训练时注入多样的上下文条件，让同一通才模型在推理时被”提示”操控：

\[ \max_\theta\ \mathbb{E}_{\mathcal{D}}\Big[\log\pi_\theta\big(\boldsymbol{a}_{t:t+H}\mid \boldsymbol{o}_{t-T:t},\ \mathcal{C}_t\big)\Big] \]

条件 \(\mathcal{C}_t\) 从语言扩展为多模态：子任务指令 \(\hat{\ell}_t\)（继承 π0.5）、子目标图像（episode 末帧——“照着这个样子做”）、episode 元数据（历史速度/质量/错误标签——“按上次的策略做”）。训练采用 CFG 式条件 dropout 保证条件可组合、可缺省：子目标图像只加进 25% 批样本；有图时 30% 概率丢弃文本子任务（图可替代文）；三个元数据项各自 5% 概率丢弃。

架构：4B VLM（含 400M 视觉编码器）+ MEM 式视频历史编码器 + 860M 流匹配专家；50 token 动作块、5 步去噪、RTC 异步分块（最大 240ms 推理延迟下仍平滑 50Hz）；执行块内 15~25 步。

实验结果。开箱即用（无任务数据微调）四能力：(1) 未见厨房/卧室环境跟随开放指令、多阶段家电任务；(2) 零样本跨本体（未见任务上叠衣）；(3) 咖啡机等硬任务上比肩 π*0.6 的 RL 专家模型，叠衣与装盒吞吐更高；(4) Coach 模式：粗指令（”倒垃圾”）可被分步详细指令逐步引导完成。意义：通才 + 条件化首次在硬任务上追平专才 RL——部署经济学被改写。

8. 实验结果分析

8.1 各代核心结果总表

代际 评测场景 核心数字 击败的对手
π0 6 个预训练零样本任务 + 20+ 微调任务 零任务数据下全部任务 >50% 最大得分；50Hz 实时灵巧；1 小时数据微调即大幅领先 OpenVLA（160k 对齐算力）、Octo（320k）、π0-small、ACT 系灵巧专用模型
FAST 高频灵巧 + 长程任务 匹配 π0 性能、训练快 5×；朴素分桶 AR 完全失败 逐维分桶 AR VLA（RT-2/OpenVLA 式）
π0.5 可复现模拟环境 → 3 个陌生真实家庭（3 厨房+3 卧室、双机型） 长程家务部分给分制达标（如”放一半碗 ≈ 50%”）；消融：去掉任一数据源均显著掉分 π0 基线、单源数据训练版
π*0.6 真机硬任务：咖啡机 / 装盒 / 叠衣 最难任务吞吐 ~2×、失败率降 2×+；13 小时连续咖啡、**2 小时+**陌生衣物、工厂级装盒 π0.5（纯模仿版）、无干预数据消融版
π0.7 开箱即用（零任务数据）：家电多阶段 / 叠衣 / 咖啡机 比肩 π*0.6 的 RL 专家；叠衣与装盒吞吐更高；零样本跨本体（UR5e）；指令跟随覆盖未见环境 RL 微调专家模型（每任务单独训练）

8.2 消融实验：π 系列的”证据链”设计

π 论文的实验不只是刷分，每篇都用消融回答一个因果问题：

消融 设置 结论 意义
算力对齐（π0） π0 只训 160k 步 = OpenVLA 同算力 仍全面胜过 OpenVLA(160k)/Octo(320k) 优势来自架构而非算力堆叠
VLM 预训练（π0） π0-small（去 VLM 骨干的小模型） π0-small 仍胜 OpenVLA/Octo；π0 又显著胜 π0-small 架构与预训练各自独立有贡献——双证据链
分词方式（FAST） 朴素分桶 vs FAST（同模型同数据） 分桶在高频灵巧上失败、FAST 复活 瓶颈定位在分词而非自回归
知识迁移（π0.5） 逐项移除多机器人/网络数据/子任务预测 每项移除都显著降泛化 异构协同是泛化的必要条件
经验与干预（π*0.6） 纯模仿 vs +自主数据 vs +专家干预 全配方（RECAP）最好 经验闭环的每一类数据都有增量价值

8.3 跨代分析：改进落点与评测哲学的演进

每一代的数字提升落在上一代的失败模式上：

  • π0 → FAST：不掉点（匹配 π0）但训练成本 ÷5——效率维度的改进
  • π0 → π0.5：从”任务成功率”转向”陌生环境完成度“（部分给分制）——泛化维度
  • π0.5 → π*0.6：从”一次成功”转向”吞吐量与失败率“（工业指标）+ 13 小时级长跑——可靠性与经济性维度
  • π*0.6 → π0.7：从”每任务 RL 专家”到”零任务数据开箱即用还追平专家”——部署成本维度

评测哲学本身在递进：静态基准（π0 的零样本任务）→ 真实家庭（π0.5）→ 工业长跑指标（π*0.6）→ 开箱即用横评（π0.7）。指标从”成功率”演进到”吞吐 / 失败率 / 干预率 / 部分完成度”——评测越来越像运营指标，反映系列从论文到产品的定位迁移。

未对齐之处（诚实标注）：π 系基本不刷 LIBERO 等公开仿真榜（主打真机），因此与 Being-H0.7 等刷榜路线没有同表可比的数字；跨家族对比只能在各自主场分别解读（见 Being-H 篇 8.2 节）。

9. 五代递进关系：能力的接力

递进的优势不是”下一代更强”，而是”每一代把上一代的能力当燃料”：

接力棒 上代留下 下代拿它做什么 证据
π0 → FAST 50Hz 高频动作块设定 证明 AR 换 FAST 分词也能吃下同款任务 FAST 匹配 π0 性能、训练快 5×
π0 → π0.5 双塔架构 + 万小时数据底座 加异构数据与子任务语义，冲出实验室 三个陌生家庭完成厨房/卧室清理
π0.5 → π*0.6 泛化通才（π0.5 骨干） 在数万小时上做离线 RL 预训练，再用部署经验在线进化 吞吐 2×、失败率减半、13h 咖啡机
π*0.6 → π0.7 RL 专家的性能天花板 + 硬任务考场 用条件化把”专家水平”蒸进通才，零任务数据开箱达线 开箱即用比肩 RL 专家、部分任务吞吐更高

三条主线贯穿：(1) 架构极稳——双塔 + 流匹配头从未更换，只有骨干换代（PaliGemma 3B → Gemma3-4B）与专家扩容（300M → 860M）；(2) 训练范式三级跳——SFT → 异构协同 → RL 经验闭环 → 条件化操控；(3) 数据哲学一贯——真机演示起步、以部署经验进化。对照 Being-H（人类视频路线，见本站解析）：π 用”经验”换能力，Being-H 用”人类先验”换能力——两线并进、尚未合流，是具身智能未来两年最大的悬念。
