常用生成范式模型介绍

VLA 具身智能 生成范式 扩散模型 自回归 流匹配 DDPM 模型选型
科研工具 数学理论基础
发布日期:   2026-09-01

VLA（Vision-Language-Action）模型的核心问题一句话：给定观测和指令，生成接下来一段动作（action chunk）。这本质是生成建模问题，而生成模型有三大主流范式：从 NLP 走来的自回归（AR）、从图像生成走来的扩散（Diffusion）、与快速崛起的流匹配（Flow Matching）。选哪个范式做动作头，是当前具身智能最热的技术路线之争。

本文是”理论 + 型号手册“的合订本：先讲清 VLA 为什么必须用生成模型、三种范式的完整数学推导，再把 2023~2026 的常用与最新 VLA 模型按范式归队逐个分析（不止”是什么”，还讲每个模型为什么这么选范式），配三个关键对照实验、纯 numpy 可运行的从零训练 demo（自回归 / DDPM / 流匹配，全部实测通过）、开源索引与参考出处。

1. VLA 为什么必须用生成模型

动作分布是多模态的。桌上一杯水，机器人可以”从左边抓”也可以”从右边抓”——两个都合理，但平均值”从中间穿过杯子”是错的。

如果用最朴素的 MSE 回归 \(\hat{\boldsymbol{a}} = \mathbb{E}[\boldsymbol{a}|\boldsymbol{o}, \boldsymbol{l}]\)，模型学到的是分布的均值——恰好落在两个模态中间的”穿模动作”。这就是行为克隆经典结论分布多模态导致回归平均（mode averaging / LARP）失败。生成模型的答案：不预测均值，而是学分布、再从分布里采样——采样天然落在某一个模态上。自回归、扩散、流匹配是”学分布”的三种不同方式。

（图源：Lilian Weng《What are Diffusion Models?》）

2. 三范式理论详解

2.1 自回归：把动作生成变成”写文本”

链式法则把联合分布拆成逐 token 条件预测：

\[ p_\theta(\boldsymbol{a} \mid \boldsymbol{o}, \boldsymbol{l}) = \prod_{t=1}^{T} p_\theta\big(a_t \mid a_{<t},\ \boldsymbol{o},\ \boldsymbol{l}\big) \]

视觉-语言编码器把观测与指令压成 token 序列，Transformer 解码器像写下一个词一样写出下一个动作 token。关键工程问题：动作连续、token 离散——RT-1 起的标准做法是每维独立均匀分桶（256 bins）；π0-FAST 的 FAST tokenizer 用 DCT 频域压缩 + BPE 把整段动作压成少量紧凑 token。

优势——擅长长期建模与文本推理：长序列连贯性由”每一帧以全部历史为条件”数学保证；天然继承 LLM 生态（指令跟随、思维链、与任意 VLM 兼容）。劣势：离散化丢精度、逐 token 生成慢、不可中途全局修正、交叉熵对连续分布只是分桶近似。

2.2 扩散（DDPM）：从噪声里”去噪”出动作

前向过程（加噪，无参数、解析可算）：

\[ q(\boldsymbol{x}_t \mid \boldsymbol{x}_{t-1}) = \mathcal{N}\big(\sqrt{1-\beta_t}\,\boldsymbol{x}_{t-1},\ \beta_t \mathbf{I}\big) \;\Longrightarrow\; \boldsymbol{x}_t = \sqrt{\bar\alpha_t}\,\boldsymbol{x}_0 + \sqrt{1-\bar\alpha_t}\,\boldsymbol{\varepsilon} \]

（\(\beta_t\) 噪声调度、\(\bar\alpha_t = \prod(1-\beta_s)\)；这个闭式一步加噪是训练基石。）

反向过程由噪声预测网络 \(\boldsymbol{\varepsilon}_\theta(\boldsymbol{x}_t, t, \boldsymbol{c})\) 学习，简化训练目标（DDPM 的核心发现）：

\[ \mathcal{L}_{\text{simple}} = \mathbb{E}_{\boldsymbol{x}_0,\,t,\,\boldsymbol{\varepsilon}}\Big[\big\|\boldsymbol{\varepsilon} - \boldsymbol{\varepsilon}_\theta\big(\sqrt{\bar\alpha_t}\boldsymbol{x}_0 + \sqrt{1-\bar\alpha_t}\boldsymbol{\varepsilon},\ t, \boldsymbol{c}\big)\big\|^2\Big] \]

采样从纯噪声出发迭代去噪 \(T\) 步。多模态自动解决：随机起点天然把样本分到不同模态。动作扩散的三个惯例由 Diffusion Policy（Chi et al., 2023）确立：整块生成 16 步动作、执行前 8 步的滚动时域、轻量 CNN/Transformer 去噪器。

（图源：Lilian Weng，原始论文 DDPM, arXiv:2006.11239）

优势——高保真与多样性：捕捉分布细节，同一指令采样多种合理解；训练稳定。劣势：几十到上百步去噪慢（DDIM/蒸馏可压）；块间缺少”以全部历史为条件”的机制，长序列全局连贯弱于 AR。

2.3 流匹配：用”直线路径”取代”千步去噪”

学一个速度场 \(v_\theta(\boldsymbol{x}, t)\)，让噪声沿 ODE \(\mathrm{d}\boldsymbol{x}/\mathrm{d}t = v_\theta\) 从 \(t{=}0\)（噪声）流到 \(t{=}1\)（数据）。条件流匹配（CFM）：噪声端 \(\boldsymbol{x}_0\sim\mathcal{N}(0,\mathbf{I})\)、数据端 \(\boldsymbol{x}_1\sim p_{\text{data}}\)，线性插值路径 \(\boldsymbol{x}_t = (1-t)\boldsymbol{x}_0 + t\boldsymbol{x}_1\)，沿路径真实速度是常数 \(\boldsymbol{x}_1 - \boldsymbol{x}_0\)：

\[ \mathcal{L}_{\text{CFM}} = \mathbb{E}\Big[\big\|\,v_\theta\big((1-t)\boldsymbol{x}_0 + t\boldsymbol{x}_1,\ t\big) - (\boldsymbol{x}_1 - \boldsymbol{x}_0)\,\big\|^2\Big] \]

采样只需几步欧拉积分 \(\boldsymbol{x} \leftarrow \boldsymbol{x} + v_\theta(\boldsymbol{x}, t)\,\Delta t\)。与扩散的关系：扩散的随机去噪可重写为概率流 ODE——扩散走弯曲路径，流匹配直接学直线。直线的三大红利：步数极少（π0 用 10 步出 50Hz 动作）、训练更稳（无噪声调度玄学、回归目标平缓）、确定性 ODE（可缓存可蒸馏）。

2.4 三范式对比

维度 自回归 扩散（DDPM 系） 流匹配
生成方式 逐 token 条件分解 随机去噪，\(T\) 步马尔可夫链 确定性 ODE，直线速度场
训练目标 交叉熵（离散） \(|\varepsilon - \varepsilon_\theta|^2\) \(|v_\theta - (x_1{-}x_0)|^2\)
动作表示 离散 token 连续 连续
采样步数 = 序列长度 10~100 ~10 步
长程连贯 ✓✓（以全部历史为条件） 块内好、块间弱 同扩散
与 LLM 生态 天然同构 需外挂动作头 需外挂动作头

选型第一性依据：离散语义空间用 AR（继承语言模型能力），连续动作空间用流匹配/扩散（保真与速度）——“AR 骨干 + 连续小头”混合架构流行的根本原因。

4. 自回归系案例：语言模型血统的延续

先驱谱系（2022-23）：Gato（DeepMind）证明单一 AR Transformer 可通吃游戏/对话/机器人控制；CLIPort 与 BC-Z 把”语言条件化模仿”跑通（CLIP 语义 + Transporter 抓放）；PaLM-E（562B）把多模态输入直接嵌入 LLM 语境，是 VLA 语言底座的直系祖先；VIMA 定义了多模态提示（图文混排指令）基准。这一代工作确立了”语言模型架构 + 动作输出”的基本盘。

RT-1 → RT-X（2022-23）。RT-1 用 13 万真实回合、700 任务证明动作 token 化 + 真机规模化的价值；RT-X 把 21 个机构的 Open X-Embodiment 数据汇成跨本体训练范式——数据集本身成为领域公共品。选型逻辑：当年唯一可扩展的范式是语言模型的 AR。

Q-Transformer（2023，DeepMind）。把 Q 学习装进 AR 动作 Transformer：离散动作 bin 上学 Q 值、取 argmax——AR + 强化学习后训练的早期范本（后来 π*0.6 的 RECAP 是同一方向的世界模型版）。

RoboFlamingo（2023，BAAI/上海AI Lab）。开源 VLM（OpenFlamingo）冻结骨干 + 轻量策略头微调——“复用开源 VLM 快速拼 VLA”的早期代表，国内社区起点。

RoboCat（2023，DeepMind）。自改进闭环：模型自己生成任务数据（目标图像 + 自演轨迹）再自训练，跨机械臂形态迁移——“自我博弈”思想进入操作领域。

RT-2（2023）。PaLI-X/PaLM-E 直接当机器人大脑，动作 token 与自然语言共同训练（co-fine-tuning），涌现符号理解与组合推理。选型逻辑：只有 AR 能让动作与语言共享同一表征空间。

OpenVLA（2024）。Llama2-7B + DINOv2/SigLIP，97 万 OXE 回合，全开源——VLA 界的”Llama 时刻”，后续开源工作的默认底座。

（图源：OpenVLA 官网，论文 arXiv:2406.09246）

OpenVLA-OFT（2025）。换掉逐 token 串行生成改并行解码连续动作块（含扩散头变体）：快 25~50 倍、成功率反升。分析：瓶颈在动作接口而非骨干——“骨干 AR + 连续小头”的结构性证据。

π0-FAST（2025）。与 π0 同骨干同数据的纯 AR 版（FAST：DCT 频域分词），任务精度与流匹配版大体打平、推理略慢但与语言栈完全统一——范式之争最干净的 A/B（见第8节）。

TinyVLA（2024-25，上海交大等）。1B→3B 小型化路线：小骨干 + 快速初始化 + 数据高效微调，主打”小模型快速域适应”，开源项目页与论文齐备。

GR-2（2024，字节）。视频生成预训练（先学预测未来画面）再迁移到操作，AR 输出动作——“看视频学做事”的预训练范式探路。

Gemini Robotics（2025→2026）。Gemini 2.0 及后续底座 + 机器人专用训练；1.5（2025 末）灵巧性/响应/安全显著提升，2 面向受信任测试者。闭源 API，代表能力上限阵营。

智元 GO-1（2025）。AgiBot World 百万级真机数据（开源）打底 + 分层大脑，数据基础设施路线的代表。

5. 扩散系案例：动作分布的精细刻画

Diffusion Policy（2023）。三板斧（chunk 16 执行 8、滚动时域、轻量去噪器）沿用至今；对多模态演示跨基准平均提升约 46.9%（论文口径）。选型逻辑：演示数据天然多模态，扩散是当时唯一稳的连续多模态方案。

Octo（2024）。93M 通用策略 + 扩散头，OXE 80 万回合——“小骨干 + 扩散头”模块化的先声，π0 架构的前身。

RDT-1B（2024，清华）。扩散 Transformer、1B、46 数据集、双臂 ALOHA 类平台事实底座。选型逻辑：双臂耦合动作分布比单臂更多模态（左右手分工组合爆炸），扩散的分布刻画直接受益。

DexVLA（2025）。视觉-语言压进统一潜空间（压缩率 ~95%），只在潜空间做扩散解码——“重理解轻解码”，训练推理双省。

DP3（2024，上海交大等）。扩散策略的 3D 化：点云编码替代 RGB 编码，每任务 3~10 条演示即可学出新技能——极少量演示 + 点云几何先验让它在实验室平台（尤其非纹理工件）上极受欢迎。

Consistency Policy（2024，Stanford 等）。把 Diffusion Policy 用一致性蒸馏压到 1~2 步出动作——扩散系对”推理慢”的自救，思路与文生图的一致性模型同源。

WorldVLA（2025，阿里）。世界模型（AR 预测下一帧）与动作生成（扩散头）互相监督——两种范式各管一个模态再互促，融合路线探路者。

6. 流匹配系案例：速度与精度的新平衡

π0（2024，Physical Intelligence）。PaliGemma 3B VLM 骨干（AR 处理语言视觉）+ 3 亿流匹配动作专家（交叉注意力挂接），10 步出 50Hz 动作块，长程灵巧任务 SOTA，权重经 openpi 开放。选型逻辑：50Hz 高频连续控制下，扩散太慢、AR 太慢，流匹配是唯一同时满足保真与速度的选项。

（图源：π0 论文 arXiv:2410.24164，官方博客）

π0.5（2025）。知识隔离（领域知识留在语言侧）+ 在线学习闭环，未见环境成功率实质提升——回答”预训练 VLA 怎么落地新家”。

π*0.6（2025 末）。Gemma3-4B + 流匹配头不变，训练升级 RECAP（RL with pretraining data）：奖励梯度混入预训练数据损失，从自身经验与人类纠错中持续改进且不灾难性遗忘；与 Ultra 合作电商包装部署、Weave 平台输出 API。分析：三步演进（π0 定架构 → π0.5 解泛化 → π*0.6 换训练范式 + 商业化），流匹配路线完成论文到产线闭环。

SmolVLA（2025，HuggingFace）。450M”VLM 骨干 + 流匹配头”，消费级显卡可训，LeRobot 生态——入门第一推荐。

GR00T N1/N1.5（2025，NVIDIA）。双系统”快慢脑”（VLM 慢思考 + DiT 动作头快输出），开源权重 + DreamGen 合成数据管线（用视频世界模型扩增训练数据）——数据侧的差异化可能比模型本身更深远。

7. 双系统与新范式

Helix（2025，Figure）。System 1：约 7B 互联网级 VLM，低频（约 7~9Hz）处理全图与语言，输出紧凑潜向量；System 2：80M 潜空间动作解码器，仅凭潜向量 + 本体感知 200Hz 高频输出。分析：不走 token 化也不走扩散采样——接口极窄所以两层各自极致优化（S2 小到能 200Hz 实时），产线级落地，闭源但架构思想被广泛借鉴（开源复现见 OpenHelix 等社区项目）。

世界模型路线。1X Neo（视频生成式世界模型做策略评估与想象训练）、UniVLA（从无标签视频先学潜动作表征再自回归）、宇树 UnifoLM-WMA（世界模型-动作一体，开放部分权重）；底座侧，DeepMind 的 Genie/Genie-2（可交互世界生成）与 NVIDIA Cosmos（世界基座模型，开源权重）为”想象训练 + 合成数据”提供基础设施——把控制问题继续向”理解世界”拉近，与 VLA 主线的融合是下一阶段最值得盯的方向。

8. 三个关键对照实验

范式之争不是口水战，是控制变量实验：

  1. π0 vs π0-FAST（同骨干同数据）：连续动作上 AR 与流匹配都到 SOTA，流匹配推理更快、AR 生态统一——分歧只剩工程取向
  2. OpenVLA vs OpenVLA-OFT（同 7B 骨干）：换动作接口（逐 token → 并行连续）快 25~50 倍且更准——瓶颈在接口不在骨干
  3. Diffusion Policy vs 回归/隐式 BC（同数据同视觉）：扩散头对多模态演示跨基准平均 +46.9%——回归必败、生成必胜的第一性证据（下一节的 demo 可以亲手复现此结论）

11. 趋势四条与选型速查

  1. 架构收敛：”AR 骨干管语义 + 连续生成小头管动作”成为默认形态（π0 系、GR00T、SmolVLA 皆然）
  2. 数据飞轮转向合成与真机规模化：DreamGen 合成、AgiBot World 百万真机——从”攒演示”转向”造数据”
  3. 训练范式从 SFT 走向 RL：π*0.6 的 RECAP、各家在线学习——“从经验中学习”取代”只模仿演示”
  4. 开源生态成熟：OpenVLA（模型）、openpi（权重）、LeRobot（训练栈）、AgiBot World（数据）——复现门槛一年降一个量级

选型速查（科研视角）：入门复现 → SmolVLA + LeRobot；追 SOTA 开源 → π0/π0.5（openpi）；7B 底座微调研究 → OpenVLA(-OFT)；双臂/ALOHA → RDT-1B；人形全栈 → GR00T N1.5；小型快速域适应 → TinyVLA。
