ACT理论与衍生VLA模型解析

VLA 模仿学习 ACT ALOHA CVAE 动作分块
论文精度与分析 模仿学习
发布日期:   2026-09-02

**ACT（Action Chunking with Transformers）**是低灵巧度机器人模仿学习的”AK-47”：约 27M 参数、一块消费级显卡可训、50Hz 实时控制——却在双臂精细任务上击败了重型 VLA。它不仅是 ALOHA 硬件的”御用大脑”，更是后续一大族 VLA 的技术母体：动作分块、CVAE 风格变量、时间集成三大发明被反复继承与替换。本文按”理论详解 → 三大发明逐个拆解（含实测 demo）→ 衍生模型逐个介绍（附开源地址与论文链接）→ 谱系总结”展开。

1. ACT 是什么：问题、方案与结果

问题设定（原论文 arXiv:2304.13705，Zhao et al. 2023）。双臂精细操作（开拉链、接线 USB 等）对模仿学习有两大挑战：复合误差（误差随步数累积，50 步任务 1mm/步的偏差会毁掉一切）与多模态演示（不同示教者用不同手法，MSE 回归会把多种手法平均成”谁也不是”的废动作）。

方案三件套：

  1. 动作分块（Action Chunking）：CVAE + Transformer 一次预测未来 \(k=100\) 步动作、每步重规划——有效视野骤降，复合误差被压制
  2. CVAE 风格变量 \(z\)：生成式建模多模态——\(z\) 编码”这次用哪种手法”，采样天然落在单一模态
  3. 时间集成（Temporal Ensemble）：重叠预测块按新旧指数加权平均——消除块边界的跳变

结果：ALOHA 低成本硬件（2 万美元双臂）上 10 分钟演示学会 6 个精细双臂任务（50 步接触富集），成功率 8090%，最高 96%（接头任务）；实时 50Hz。开源于 tonyzhaozh/act，LeRobot 内置 --policy.type=act。

2. 理论详解

2.1 CVAE：生成式模仿学习的数学

ACT 的策略是条件变分自编码器 \(\pi_\theta(\boldsymbol{a}_{1:k}\mid \boldsymbol{o}_t)\)。引入隐变量 \(z\)（维度仅 32）拆解多模态：

\[ p_\theta(\boldsymbol{a}_{1:k}\mid\boldsymbol{o}_t)=\int p_\theta(\boldsymbol{a}_{1:k}\mid z,\boldsymbol{o}_t)\, p_\theta(z\mid\boldsymbol{o}_t)\,\mathrm{d}z \]

训练（ELBO）——编码器读演示动作序列（加”风格 token”）输出后验 \(q_\phi(z\mid \boldsymbol{a}_{1:k}, \boldsymbol{o}_t)\)，与先验 \(p(z)=\mathcal{N}(\mathbf{0},\mathbf{I})\) 对齐：

\[ \mathcal{L}=\underbrace{\mathbb{E}_{q_\phi}\big[-\log p_\theta(\boldsymbol{a}_{1:k}\mid z,\boldsymbol{o}_t)\big]}_{\text{重建}}+\underbrace{\beta\, D_{\mathrm{KL}}\big(q_\phi(z\mid \boldsymbol{a}_{1:k},\boldsymbol{o}_t)\,\|\,p(z)\big)}_{\text{先验对齐}} \]

推理：编码器丢弃，\(z\sim\mathcal{N}(\mathbf{0},\mathbf{I})\)（或 CLIP 编码），解码器（CVAE-Transformer）基于观测与 \(z\) 直接输出整块动作。\(z\) 的物理含义就是”风格”——同观测不同 \(z\) 对应不同手法，这是多模态的解。

2.2 架构：27M 参数的 CVAE-Transformer

解码器是标准 Transformer：观测 token + \(z\) token 作为前缀，自回归出 \(k\) 步动作。仅 ~27M 参数（对比 π0 的 3.3B 是 1/120）。

2.3 时间集成：重叠块的指数加权平均

每步重规划会产生最多 \(k\) 个覆盖当前时刻的预测（年龄 0~\(k{-}1\)），按指数权重平均：

\[ \hat{a}_t=\sum_{j=0}^{k-1}\underbrace{w^j}_{\text{年龄}j\text{ 的权重}}\,a^{(j)}_t\ \Big/\ \textstyle\sum_j w^j,\qquad w<1 \]

各预测块的系统偏差在平均中互相抵消，块边界不再跳变。

4. 衍生模型逐个介绍：改了什么、怎么改、达到什么效果

ACT 的三大发明像基因一样扩散。以下按”改了哪个部件”分组，每个模型分改动（相对 ACT 的具体修改）与效果（量化结果）两段，全部给出论文与开源地址。

4.1 硬件与数据扩展系【直接继承全套算法，改数据或平台】

Mobile ALOHA（2024，斯坦福，arXiv:2401.02117）。

  • 改动：算法零改动——完整继承 ACT 的 CVAE + chunk + 时间集成；唯一的变化在数据侧：(1) 硬件加移动底盘，遥操作采集全身数据；(2) 共同训练（co-training）——把原 ALOHA 静态数据（60% 权重）与新采的移动操纵数据（40% 权重）混合训练，静态数据的精细操作技能”免费”迁移给移动平台
  • 效果：每个任务仅 50 次演示，即可学会烧饭（虾炒西兰花，需开火、翻炒、加盐、关火多阶段）、开电梯按楼层、叫电梯等多阶段长程家务——而纯移动数据训练无法达到同等精细度，证明共训的迁移价值。开源 tonyzhaozh/mobile-aloha + mobile-aloha.github.io（全套硬件文档）

ALOHA Unleashed（2024，Google DeepMind/斯坦福，CoRL 2024，arXiv:2410.13126）。

  • 改动：同样是算法微调、数据配方为主——在 ALOHA 双臂上调整演示质量与数据量配比，用简单模仿学习实现高灵巧行为；核心主张是”演示质量 > 模型复杂度”
  • 效果：实现手内绕线（把线穿过扣子孔）、拉开胶带座等此前只在灵巧手上实现的高难度任务——用平行夹爪而非灵巧手。ACT 作者 Zhao 与 DeepMind 团队（Finn/Driess/Florence）联名

UMI 家族（2024-25，斯坦福）。数据接口民主化路线：

  • 改动（UMI，arXiv:2402.10329）：不直接改 ACT 算法，而是换掉整个数据采集层——手持夹爪（GoPro + 3D 打印裙边）让任何人野外教学，夹持器几何恒定消除相机-末端外参、GoPro 时间戳消除时间同步问题；策略头用 Diffusion Policy（继承 chunk 思想，生成头换扩散）
  • 效果：零机器人真机演示，纯人类手持数据训练的策略直接在新环境零样本部署（咖啡制作、蛋卷、衣物折叠等）
  • 后续：FastUMI（arXiv:2409.19499）把推理从云端移到边缘设备并降延迟成本；UMI on Legs（arXiv:2407.10353）把策略装上四足机器人做移动操作。开源 real-stanford/universal_manipulation_interface

4.2 视触觉与力觉系【改观测融合层，保留 CVAE 骨干】

ViTacFormer（2025，Berkeley/北大/Sharpa，arXiv:2506.15953）。明确基于 ACT 构建（原论文：”我们的 ViTacFormer 是在 ACT 的基础上构建的，利用了其在多样专家数据中捕获多模态的优势”），是”ACT + 触觉”的代表作：

  • 改动（三处，全部围绕触觉）：

    1. 观测融合重设计：ACT 的朴素 token 拼接 → 交叉注意力融合——视觉的 K/V 对触觉的 Q 计算（反之亦然），双向捕获模态间相关性（”看哪里就知道会摸到什么、摸到什么就知道该看哪里”）
    2. 加自回归触觉预测头：ACT 只生成动作 → ViTacFormer 先预测未来触觉 token，再以预测的触觉为条件生成动作——“预期接触”被编码进潜表征，支撑精确自适应操作
    3. 两阶段课程训练：前 75% 用真实未来触觉 token（稳定表征学习），后 25% 切换到预测的触觉（提升鲁棒性）

    损失函数从 ACT 的两项扩为四项：\(L = w_1 L_{\mathrm{KL}} + w_2 L_{\mathrm{JA}} + w_3 L_{\mathrm{tactile}} + w_4 L_{\mathrm{arm}}\)

  • 效果：硬件为双 Realman 臂 + SharpaWave 灵巧手（指尖 320×240 高分辨率触觉），外骨骼手套 + VR 遥操作采集。比之前 SOTA 成功率高约 50%；首个用拟人手自主完成 11 个连续阶段的长视野灵巧任务（持续 2-5 分钟）——如拉拉链、系扣子等需要视觉遮挡下力反馈的精细操作。开源 github.com/RoboVerseOrg/ViTacFormer，项目页。本站有专文精读

Bi-ACT 双边控制系（2024，千叶工大）。

  • 改动：不改生成头——把**双边控制（bilateral control）**的位置与力信息作为额外观测输入注入 ACT。双边控制是主从臂实时互传位置与力的控制范式，Bi-ACT 让 ACT 的观测向量从”只看关节位置”扩展为”位置 + 力”
  • 效果：低成本单臂版（arXiv:2401.17698）与双臂版 ALPHA-α（arXiv:2411.09942）：物体刚度/质量变化时适应力显著优于原版 ACT——力觉信息让策略能感知”碰到软的还是硬的”

4.3 换生成头系【保留 chunk 与观测设计，换掉 CVAE】

Diffusion Policy（2023，哥伦比亚/TRI，arXiv:2303.04137）。与 ACT 并列的双雄：

  • 改动：CVAE 头 → 扩散去噪头（DDPM）。多模态能力的来源从”隐变量采样”换成”随机噪声起点”——同一观测从不同噪声出发去噪到不同模态；视觉编码器加了空间下采样（保留空间精度）；两种骨干（1D CNN 时序卷积 / Transformer）替代 ACT 的纯 Transformer
  • 效果：跨基准对 BC-RNN 等基线平均提升 46.9%；与 ACT 互有胜负（接触富集任务 ACT 略优、长视野 Diffusion 略优）；其 vision encoder 设计被后续大量复用（含 π0 也在其基础上改进）。开源 real-stanford/diffusion_policy

3D Diffuser Actor（2024，CMU，arXiv:2402.10885）。观测侧升级 + 扩散头：

  • 改动：2D 图像观测 → 3D 场景特征（PerAct 风格的体素/多视角特征融合），动作侧扩散去噪 3D 末端执行器轨迹（而非关节空间）；加语言条件（CLIP 编码）实现任务指定
  • 效果：RLBench 与 CALVIN 双 SOTA，语言泛化能力强；证明 3D 几何先验在多任务场景的价值。开源 nickgkan/3d_diffuser_actor，项目页

VQ-BeT（2024，NYU，arXiv:2403.03181）。分词系换头：

  • 改动：CVAE 采样 → 动作块先经 VQ-VAE 离散化（层级码本：粗”动作原型” token + 细”偏移” token），再由 GPT 式 Transformer 自回归预测 token 序列。多模态由 token 分布天然承载，无需隐变量或扩散
  • 效果：在 PushT 多模态基准上超 ACT 与 Diffusion Policy；RLBench 及真机验证长视野任务；可同时做条件生成与轨迹预测（同一模型两种推理模式）。详见本站运动离散化技术。开源 jayLEE0301/vq_bet_official，LeRobot 内置 vqbet

KUDA（2025，UIUC/斯坦福，ICRA 2025，arXiv:2503.10546）。关键点 + 逆动力学系换头：

  • 改动：视觉编码 → 2D 关键点提示（由 VLM 指定），关键点经 逆动力学模型（IDM）生成动作块——策略学的是”怎么让这个关键点到那里”而非”什么动作序列正确”；VLM（GPT-4o）做任务规划与关键点选择，分层解耦”想”与”动”
  • 效果：开放词汇任务——用自然语言指定新物体/新目标无需重训策略（换关键点提示即可）；在真实机器人上验证跨物体类别泛化。开源 kvignesh14/kuda

4.4 训练范式改进系【保留架构，改训练目标/理论】

Action Matching（AM）（2023，Meta，arXiv:2310.13727）。理论级贡献：

  • 改动：不提出新架构——把 CVAE/扩散/流匹配统一为”分布间的随机插值 + 回归”框架（Action Matching），证明 CVAE/GEN/Diffusion/Flow Matching 全是 AM 的特例：CVAE 对应独立耦合（插值方差最大），扩散/流匹配对应确定性耦合（方差最小）
  • 效果：理论解释了为什么各种生成头都能解多模态、以及各自的方差差异来源；AM 本身在部分基准上用更简单的一步推理达到扩散级性能。开源 StanfordVL/action-matching-models。读 ACT 系理论必读此文

π0 系（2024-2026，Physical Intelligence，详见本站PI 系列解析）。

  • 改动：27M 小模型 → 3.3B VLM 底座（PaliGemma 3B + 300M 动作专家，后续 Gemma3-4B + 860M）；CVAE 头 → 流匹配头（CFM 线性插值路径，10 步 Euler 采样）；~50 条演示 → 1 万小时跨平台数据 + OXE；chunk 从 k=100 @50Hz 改为 H=50 @50Hz
  • 效果：50Hz 灵巧任务（叠衣等）；”对齐算力”消融证明架构而非算力是优势来源；后续 FAST（arXiv:2501.09747）在 ACT 的 CVAE-Transformer 骨干上换 DCT 分词，AR 与流匹配打平——ACT 架构的直接延续验证。开源 Physical-Intelligence/openpi

4.5 生态位总结

一句话：ACT 定义了”精细操作 = 动作块 + 多模态生成头”的配方，后续工作在”生成头怎么造、观测怎么编码（2D/3D/触觉/力）、数据从哪来（遥操作/手持接口/人类视频/万小时真机）”三个轴上各自替换。与 π 系（真机数据哲学）和 Being-H 系（人类视频哲学）相比，ACT 系的生态位是”低成本硬件 + 少量演示 + 精细接触任务”——三者至今并存互补。

5. 实验结果分析

原论文 6 任务（ALOHA 真机，每个 50 次演示）：拉链袋开合、糖果挑选、胶带拾取、咖啡杯倒豆、USB 接插（最难）、玩具标签翻面——成功率 80%~96%，全部超过 BC-RNN 与 IBC 基线；消融三连：去掉 CVAE（纯确定性）成功率掉 ~20pp（多模态演示下尤惨）、去掉 chunk（逐帧预测）因复合误差几乎全部失败、去掉时间集成块间抖动显著。速度：27M 参数 + 50Hz 实时（RTX 3060 级即可）。

衍生系对照：Diffusion Policy 在其自设基准上对 BC-RNN 平均 +46.9%（与 ACT 互有胜负，接触富集任务 ACT 略优、长视野 Diffusion 略优）；VQ-BeT 在 PushT 等多模态基准上超 ACT 与 Diffusion Policy；π0-FAST 与流匹配版打平证明分词才是 AR 瓶颈；Mobile ALOHA 共训使长程家务从几乎 0 到可用。
