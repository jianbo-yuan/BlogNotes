Diffusion Policy理论与衍生VLA模型解析

VLA 扩散模型 Diffusion Policy 模仿学习 DDIM 3D策略
论文精度与分析 模仿学习
发布日期:   2026-09-02

Diffusion Policy（Chi et al. 2023，哥伦比亚/TRI）用一篇论文改变了机器人模仿学习的格局：把文生图的扩散去噪搬到动作生成上，跨基准平均提升 46.9%。它不仅与 ACT 并列为精细操作的”双雄”，更催生了 3D 策略、一致性蒸馏、残差扩散、引导扩散人形控制等一整条技术树——包括本站已有精读的 BeyondMimic。本文按”理论详解（含实测 demo）→ 衍生模型逐个拆解（改动/效果双段式）→ 谱系总结”展开，与 ACT 解析互为姊妹篇。

1. Diffusion Policy 是什么：问题、方案与结果

问题设定（arXiv:2303.04137）。模仿学习的两大老难题与 ACT 完全一致：多模态演示（MSE 回归模式平均）与复合误差（逐帧预测的误差累积）。此外 Diffusion Policy 论文额外指出第三个：高维动作空间的分布建模——机器人的动作空间是高维连续的，之前的生成方法（GAN 不稳定、CVAE 采样模糊）各有瓶颈。

方案：动作块扩散去噪。策略网络 \(\epsilon_\theta(\boldsymbol{A}^k, k, \boldsymbol{o})\) 学习从纯噪声逐步去噪出未来 \(T_p = 16\) 步动作块，每次推理从随机噪声出发、\(T_d\) 步去噪到干净动作，执行前 8 步、丢弃后 8 步（滚动时域）。

结果：15 个基准（PushT、RoboMimic 等），跨基准平均比 BC-RNN/IBC 提升 46.9%；真机（UR5、Franka）验证接触富集任务（腌黄瓜取放、倒坚果等）。开源 github.com/real-stanford/diffusion_policy，LeRobot 内置 diffusion。

2. 理论详解

2.1 从 DDPM 到动作扩散（数学回顾）

详见本站运动离散化/生成范式的 DDPM 推导。核心三公式：

前向加噪（闭式可算）：\(\boldsymbol{A}^k = \sqrt{\bar\alpha_k}\boldsymbol{A}^0 + \sqrt{1-\bar\alpha_k}\,\boldsymbol{\varepsilon}\)

训练目标（噪声预测）：\(\mathcal{L} = \mathbb{E}\big[\|\boldsymbol{\varepsilon} - \boldsymbol{\varepsilon}_\theta(\boldsymbol{A}^k, k, \boldsymbol{o})\|^2\big]\)

反向去噪（DDPM）：\(\boldsymbol{A}^{k-1} = \mu_\theta(\boldsymbol{A}^k, k, \boldsymbol{o}) + \sigma_k \boldsymbol{z}\)

2.2 多模态的来源：随机噪声起点

扩散解多模态的机制与 CVAE 不同：随机起点自动分模态。不同噪声去噪到不同模态——不需要显式的隐变量或聚类。推理时随机采样 \(T\) 次可以得到多个合理动作方案。

2.3 与 CVAE（ACT）的机制对比

维度 ACT（CVAE） Diffusion Policy
多模态来源 隐变量 \(z\) 编码”风格” 随机噪声起点
训练稳定性 ELBO 联合优化（需平衡重建/KL） 回归噪声（简单稳定）
采样步数 1 步（\(z\) + 前向解码） \(T_d\) 步去噪（10~100）
高维动作 受限于 VAE 容量 扩散逐步精修更适配
速度 ✓ 快 需 DDIM/蒸馏加速
少量演示 ✓ 更优（论文互证） 略逊但可接受

2.4 架构两种：CNN 与 Transformer

Diffusion Policy 提供两种去噪骨干：

  • 1D 时序 CNN（默认）：对 \(T_p \times \dim\) 的动作块做 1D 卷积——感受野有限但参数少、训练快、对短块（16 步）足够
  • Transformer：全局自注意力——更长视野、更大动作维度（如双臂全身控制）更优

视觉编码：ResNet-18（空间下采样保留 2D 精度）——比 ACT 的 CNN 编码器增加了空间分辨率保留设计（ACT 用 stride 池化压缩到 1×1，DP 保留 feature map 结构）。

2.5 推理加速路线

方法 原理 步数
DDPM（原版） 逐步随机去噪 50~100
DDIM（确定性采样） 跳步确定性 ODE 10~20（DP 默认）
Consistency Policy（衍生） 一致性蒸馏 1~2
流匹配（另一路线） 直线路径速度场 ~10（见 π0）

4. 衍生模型逐个介绍：改了什么、达到什么效果

4.1 3D 策略系【观测从 2D 换 3D】

3D Diffusion Policy（DP3）（2024，上海交大，arXiv:2403.03954）。

  • 改动：2D 图像观测 → 3D 点云（稀疏采样，仅 5121024 点）；每个任务仅需 310 条演示（DP 需 50~200 条）。视觉编码器用轻量 PointNet++（而非 ResNet），其余扩散去噪架构不变
  • 效果：跨 70+ 任务验证（真实机器人与仿真），极少量演示下成功率显著超 2D DP——3D 几何先验让模型不需要从 2D 图像”猜”深度。开源 github.com/YanjieZe/3DDiffusionPolicy。LeRobot 社区广泛使用

3D Diffuser Actor（2024，CMU，arXiv:2402.10885）。

  • 改动：单视角点云 → 多视角 3D 场景特征（PerAct 风格体素 + 多视角 RGB 特征投影），动作侧扩散去噪 3D 末端轨迹；加 CLIP 语言条件
  • 效果：RLBench 与 CALVIN 双 SOTA；语言任务泛化强。开源 github.com/nickgkan/3d_diffuser_actor

4.2 加速系【减步数，保精度】

Consistency Policy（2024，Stanford/TRI，arXiv:2405.07503）。

  • 改动：把 Diffusion Policy 用一致性蒸馏（consistency distillation）压到 1~2 步出动作——训练一个”一步到干净动作”的学生网络，教师是原 DP 的去噪网络；保留 DP 的 CNN 骨干与滚动时域设计
  • 效果：在 DP 的全部基准上精度持平或更优、推理提速 4~10×（从 DDIM 10 步降到 1~2 步），真机实时帧率可达 45Hz+。开源 github.com/real-stanford/consistency_policy

4.3 残差与多阶段系【扩散出修正量而非绝对动作】

ChainedDiffuser（2024，亚琛工大，arXiv:2409.16461）。

  • 改动：DP 的扩散头输出绝对动作 → 改为输出相对粗规划的残差修正：先用逆运动学/采样得到粗轨迹，扩散头学习”真实演示 - 粗轨迹”的残差——降低扩散需要建模的分布复杂度
  • 效果：在长视野任务上精度提升，扩散的建模负担减半

4.4 人形与全身控制系【扩散进运动控制】

BeyondMimic（2024/2025，项目页）。本站已有专文精读。

  • 改动：扩散进人形全身运动控制——不是操作策略，而是”跟踪目标动作到物理可行的人形运动”的引导扩散：物理引导（接触/平衡约束）+ 语义引导（风格一致性）
  • 效果：人形跟随任意目标动作（动捕/视频提取），物理可行且风格自然

Diffusion Forcing（2024，MIT，arXiv:2407.01392）。

  • 改动：DP 的”整块统一去噪” → 每个时间步独立噪声水平：为动作块的每一步分配独立的噪声调度，训练时随机混合”干净步与噪声步”——统一了序列预测与扩散去噪的框架
  • 效果：长视野稳定性提升；在机器人控制与视频预测双验证

4.5 VLA 整合系【扩散作为大模型底座的动作头】

π0（2024，Physical Intelligence，详见本站PI 系列解析）。

  • 改动：孤立的扩散/流匹配去噪器 → 与 VLM 骨干全注意力交互的流匹配动作专家（π0 用流匹配而非扩散——扩散的”直路化”升级，理论见生成范式流匹配节）；噪声调度 → 线性插值路径（更直、更少步数）
  • 效果：50Hz 灵巧任务（叠衣）；1 万小时数据 + VLM 底座；”对齐算力”消融证明架构优势

Octo（2024，Berkeley 等，arXiv:2405.12213）。

  • 改动：单任务扩散策略 → 通用策略：OXE 80 万回合跨本体训练，扩散头出动作；任务/机器人指令通过 token 化条件注入（首创新”readout tokens”）
  • 效果：零样本跨任务/机器人适配，微调后超专用基线。开源 github.com/octo-models/octo

RDT-1B（2024，清华，arXiv:2410.07864）。

  • 改动：扩散去噪器从 CNN/小 Transformer → 1B 扩散 Transformer（DiT）；单臂 → 双臂（ALOHA 类平台）； 46 数据集百万回合训练
  • 效果：扩散系最大开源基座；双臂协同任务（叠衣、倒水等）SOTA。开源 github.com/thu-ml/RoboticsDiffusionTransformer

OpenVLA-OFT（2025，Berkeley，arXiv:2502.19645）。

  • 改动：OpenVLA 的逐 token 离散动作 → 并行扩散头出连续动作块（另有 L1 回归变体）；保留 OpenVLA 的 7B VLM 骨干
  • 效果：推理提速 25~50×、Bridge/Fractal 等基准成功率反升。开源 github.com/moojink/openvla-oft

4.6 生态位总结

衍生方向 模型 改动轴 标志效果
3D 观测 DP3 2D 图像 → 3D 点云 3~10 条演示即学会
3D 多视角 3D Diffuser Actor → 多视角体素 + 语言 RLBench/CALVIN SOTA
加速 Consistency Policy DDIM 10 步 → 一致性 1~2 步 提速 4~10×，精度持平
残差修正 ChainedDiffuser 绝对动作 → 粗规划+残差 长视野精度提升
人形全身 BeyondMimic 操作 → 全身运动引导扩散 物理可行人形跟随
噪声设计 Diffusion Forcing 统一噪声 → 逐步独立噪声 长视野稳定
VLM 整合 π0（流匹配） 孤立扩散 → VLM 挂接流匹配专家 50Hz 叠衣
通用策略 Octo 单任务 → 80 万回合跨本体 零任务适配
双臂基座 RDT-1B → 1B DiT + 双臂 双臂 SOTA
7B 扩散头 OpenVLA-OFT → 7B VLM + 并行扩散头 快 25~50× 且更准

一句话：Diffusion Policy 定义了”动作 = 扩散去噪”的配方，后续在”观测维度（2D→3D→多视角）、推理速度（10 步→2 步→流匹配 10 步直线）、与语言底座的整合（孤立→VLM 挂接→7B）”三个轴上演进。与 ACT 系（隐变量路线）互补：少演示/精细接触用 ACT 系，大数据/多任务/高维用扩散系——两条路在 π0（流匹配 = 扩散的直线化）处合流。

5. 实验结果分析

原论文（15 基准）：跨基准对 BC-RNN/IBC 平均 +46.9%；消融三连：CNN vs Transformer（短块 CNN 优、长块 Transformer 优）、视觉编码空间下采样保留（去掉掉 20%+）、DDIM 步数（10 步够用，50 步无显著增益）。与 ACT 的正面交战：PushT 上 DP 胜、真机精细任务 ACT 胜——两者互补而非替代。

衍生系对照：DP3 极少演示场景完胜 2D DP；Consistency Policy 全基准保持精度并提速一个量级；Octo 零样本适配 Open X-Embodiment 全域；RDT-1B 在双臂叠衣上超越 DP 与 ACT；π0 流匹配在 50Hz 灵巧任务上证明”扩散直线化”的价值。
